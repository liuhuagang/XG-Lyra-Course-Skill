# Character Initialization & Movement System

## Overview

This chapter covers the complete initialization flow from "being spawned" to "becoming controllable" for a character, along with key extensions to the movement system.

---

## PlayerSpawningManager: Player Spawning Management

**File**: `Source/LyraGame/Player/LyraPlayerSpawningManagerComponent.h`

`ULyraPlayerSpawningManagerComponent` inherits from `UGameStateComponent`, mounted on `ALyraGameState`, and uniformly manages player spawn point allocation.

```cpp
UCLASS()
class ULyraPlayerSpawningManagerComponent : public UGameStateComponent
{
    GENERATED_BODY()

public:
    virtual AActor* OnChoosePlayerStart(AController* Player, TArray<APlayerStart*>& Starts);
    APlayerStart* GetBestPlayerStart(AController* Player);
    virtual void InitializeStarts();

protected:
    TArray<APlayerStart*> PlayerStarts;
    TSet<APlayerStart*> OccupiedStarts;
};
```

### Spawning Flow

```
ALyraGameMode::HandleStartingNewPlayer
  → ULyraPlayerSpawningManagerComponent::OnChoosePlayerStart
    → Selects appropriate start from PlayerStarts
    → Considers: team affiliation, occupancy, priority
  → SpawnDefaultPawnAtTransform
    → Creates ALyraPawn
    → Initializes PawnExtensionComponent (InitState state machine starts)
  → Possess Pawn
    → PlayerController takes control of Pawn
```

### Team Spawning Logic

- Filters spawn points matching team tags from `PlayerStarts`
- Spawn points for the same team are arranged in zones
- `PlayerStartTag` marks spawn points for specific teams

## Movement System & Acceleration Replication

**File**: `Source/LyraGame/Character/LyraCharacterMovementComponent.h`

`ULyraCharacterMovementComponent` inherits from `UCharacterMovementComponent`, injected by `ALyraCharacter` via `SetDefaultSubobjectClass` in the constructor.

### Acceleration Replication (FLyraReplicatedAcceleration)

Lyra quantizes the acceleration vector from Cartesian to Polar coordinates, reducing network bandwidth usage:

```cpp
struct FLyraReplicatedAcceleration {
    uint8 AccelXYRadians;    // Horizontal angle [0, 255], quantized from Cartesian→Polar
    uint8 AccelXYMagnitude;  // Horizontal magnitude [0, 255]
    int8  AccelZ;            // Vertical component [-127, 127]
};
```

Replication conditions target simulated clients only:

```
Server
  ALyraCharacter::PreReplication()
    → CartesianToPolar(FVector) → Quantize → FLyraReplicatedAcceleration

Replication condition
  DOREPLIFETIME_CONDITION(ReplicatedAcceleration, COND_SimulatedOnly)

Client
  ALyraCharacter::OnRep_ReplicatedAcceleration()
    → PolarToCartesian → FVector
    → ULyraCharacterMovementComponent::SetReplicatedAcceleration(FVector)
```

### SimulateMovement Override

```cpp
void ULyraCharacterMovementComponent::SimulateMovement(float DeltaTime)
{
    if (bHasReplicatedAcceleration)
    {
        Acceleration = ReplicatedAcceleration;
    }
    Super::SimulateMovement(DeltaTime);
}
```

### Ground Detection (FLyraCharacterGroundInfo)

Frame-cached ground detection results avoid repeated Traces within the same frame:

```cpp
struct FLyraCharacterGroundInfo {
    uint64 LastUpdateFrame;        // Cached frame count
    FHitResult GroundHitResult;    // Hit result
    float GroundDistance;          // Distance to ground
};
```

- MOVE_Walking mode: GroundDistance = 0
- Other modes: line trace downward from capsule center minus half height

### Tag-Controlled Movement

`ULyraCharacterMovementComponent` uses GameplayTags to control character movement:

```cpp
FRotator ULyraCharacterMovementComponent::GetDeltaRotation(float DeltaTime) const
{
    if (HasMatchingGameplayTag(TAG_Gameplay_MovementStopped))
        return FRotator(0, 0, 0);  // No rotation
    return Super::GetDeltaRotation(DeltaTime);
}

float ULyraCharacterMovementComponent::GetMaxSpeed() const
{
    if (HasMatchingGameplayTag(TAG_Gameplay_MovementStopped))
        return 0;  // No movement
    return Super::GetMaxSpeed();
}
```

### Crouched Jump

`CanAttemptJump()` removes the `IsCrouched()` check from the parent class, allowing the character to jump while crouching.

Lyra uses FastShared replication mode to provide high-frequency position updates for simulated clients. See the character class hierarchy for details.

## Key Design Points

1. **PlayerSpawningManager unified management** — Replaces traditional AGameModeBase::ChoosePlayerStart, supports team zones and conflict avoidance
2. **Acceleration Polar quantization** — Cartesian→Polar compression reduces bandwidth, COND_SimulatedOnly syncs only to simulated clients
3. **Ground detection frame caching** — FLyraCharacterGroundInfo caches per frame, avoiding multiple Traces in a single frame
4. **Tag-controlled movement** — GameplayTags directly control rotation/speed, no hardcoded state checks
5. **Crouched Jump** — Removes crouch jump restriction, increasing movement flexibility
