# Outline / Stencil

## Architecture Overview

Outline technology is used to highlight contours around characters and objects. In Lyra, it is used to distinguish characters from different teams.

## Implementation

Uses a **post-process material + Stencil buffer** approach:

1. **Enable Stencil** — Enable Custom Depth-Stencil Pass in project settings
2. **Set Stencil Value** — Set the Custom Depth Stencil Value on meshes that need outlines (to distinguish teams)
3. **Post-Process Material** — Samples `CustomStencil` values, draws outlines on difference boundaries

### Key Technical Points

- **Team Distinction**: Different teams use different stencil values
- **Depth Detection**: Checks `CustomDepth` vs `SceneDepth` difference to determine occlusion
- **Edge Detection**: 4-directional sampling of `CustomStencil` to detect change boundaries
- **Per-View Switching**: Outline effect is attached to each PlayerController's camera; different players see different effects

## Color Updates

- Listens to team change events (UAsyncAction_ObserveTeamColors)
- Dynamically updates outline color when a character switches teams

## Notes

- Performance impact comes primarily from the Custom Depth Pass draw overhead
- Only enable Custom Depth on characters that need outlines, avoid enabling it scene-wide
