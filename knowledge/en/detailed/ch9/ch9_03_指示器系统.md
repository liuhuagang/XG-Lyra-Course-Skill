# Indicator System

## Architecture Overview

The indicator system renders world object markers in screen space (health bars, names, interaction prompts, etc.), supporting screen-edge clamping, arrow indicators, priority sorting, and object pool reuse.

Core file: [UI/IndicatorSystem/](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/UI/IndicatorSystem/)

## Slate Canvas

[SActorCanvas](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/UI/IndicatorSystem/SActorCanvas.h)

```cpp
class SActorCanvas : public SPanel, public FAsyncMixin, public FGCObject
{
    // Child categories
    TArray<FSlot> CanvasChildren;   // Normal indicators
    TArray<FSlot> ArrowChildren;     // Screen-edge arrow indicators
    FSlotChildren AllChildren;       // Merged child set

    // Per-frame update
    EActiveTimerReturnType UpdateCanvas(double CurrentTime, float DeltaTime);
    void UpdateActiveTimer();

    // Add/remove indicators
    void AddIndicatorForEntry(UIndicatorDescriptor* Indicator);
    void RemoveIndicatorForEntry(UIndicatorDescriptor* Indicator);
};
```

### Core Features

1. **Pre-allocated Arrows**: Pre-allocates 10 arrow Widgets on construction
2. **ActiveTimer**: Drives projection calculation and layout update per frame
3. **Projection Calculation**: Converts world coordinates to screen coordinates based on projection mode
4. **Screen-Edge Clamping**: Determines indicator position at screen edges via `SegmentPlaneIntersection`
5. **Sorting**: Sorts by Priority → Depth
6. **Object Pool**: `IndicatorPool` manages Widget reuse

### Slot Structure

```cpp
struct FSlot
{
    ScreenPosition;     // Screen position
    Depth;              // Depth (Z-sort)
    Priority;           // Priority
    Visibility;         // Visibility
    DirtyFlags;         // Dirty flags
};
```

## Interaction System Integration

In `ULyraGameplayAbility_Interact::UpdateInteractions`:

```cpp
for (auto& Option : InteractiveOptions)
{
    UIndicatorDescriptor* Indicator = NewObject<UIndicatorDescriptor>();
    Indicator->SetDataObject(InteractableTargetActor);
    Indicator->SetSceneComponent(InteractableTargetActor->GetRootComponent());
    Indicator->SetIndicatorClass(InteractionWidgetClass);
    IndicatorManager->AddIndicator(Indicator);
}
```

- Interaction targets automatically generate indicators
- Indicators follow the interaction target's movement
