# Session System

## Overview

Lyra's session system is built on `UCommonSessionSubsystem`, supporting creating, finding, and joining game sessions. The system supports both OSSv1 and OSSv2 (Online Subsystem), and provides a QuickPlay mechanism for fast matchmaking.

## Core Classes

### UCommonSessionSubsystem

- **Inheritance**: `UGameInstanceSubsystem` → `UCommonSessionSubsystem`
- **Responsibility**: Manages the full lifecycle of online sessions

## Session Flow

### HostSession

```
HostSession(APlayerController*, UCommonSession_HostSessionRequest*)
  ├── Offline mode: Immediate ServerTravel(ConstructTravelURL())
  └── Online/LAN mode:
        └── CreateOnlineSessionInternal(LocalPlayer, Request)
              ├── OSSv1: Sessions->CreateSession(*UserId, NAME_GameSession, HostSettings)
              │     HostSettings include:
              │       SETTING_GAMEMODE, SETTING_MAPNAME,
              │       SETTING_MATCHING_TIMEOUT=120,
              │       SETTING_SESSION_TEMPLATE_NAME="GameSession"
              └── OnCreateSessionComplete(FName SessionName, bool bWasSuccessful)
                    └── FinishSessionCreation(bWasSuccessful)
                          ├── Success: ServerTravel(PendingTravelURL) + NotifyCreateSessionComplete
                          └── Failure: SetCreateSessionError + NotifyCreateSessionInformationUpdated(OutOfGame)
```

### FindSessions

```
FindSessions(APlayerController*, UCommonSession_SearchSessionRequest*)
  └── FindSessionsInternalOSSv1:
        SearchSettings->QuerySettings.Set(SETTING_SESSION_TEMPLATE_NAME, "GameSession", Equals)
        Sessions->FindSessions(SearchSettings)
          └── OnFindSessionsComplete → Results stored in SearchRequest->Results
```

### QuickPlay

```
QuickPlaySession(APlayerController*, UCommonSession_HostSessionRequest*)
  └── HandleQuickPlaySearchFinished
        ├── Results > 0: JoinSession(first result)
        ├── Results == 0: HostSession
        └── Failure: NotifySessionInformationUpdated(OutOfGame)
```

### JoinSession

```
JoinSession(APlayerController*, UCommonSession_SearchResult*)
  └── JoinSessionInternalOSSv1:
        Request->Result.Session.SessionSettings.bUsesPresence = true
        Sessions->JoinSession(*UserId, NAME_GameSession, Request->Result)
          └── Success: ServerTravel
```


## UCommonSession_HostSessionRequest Parameters

| Parameter | Type | Description |
|------|------|------|
| OnlineMode | ECommonSessionOnlineMode | Offline/LAN/Online |
| bUseLobbies | bool | Whether to use lobbies |
| bUseLobbiesVoiceChat | bool | Lobby voice chat |
| bUsePresence | bool | Use Presence |
| MapID | FPrimaryAssetId | Map resource ID |
| ModeNameForAdvertisement | FString | Advertisement mode name |
| ExtraArgs | TMap<FString, FString> | Extra arguments (Experience, DemoRec, etc.) |
| MaxPlayerCount | int32 | Maximum players (default 16) |

## ECommonSessionOnlineMode

- **Offline**: Offline mode, direct ServerTravel, no online session created
- **LAN**: LAN mode
- **Online**: Online mode
