# Game Settings Screen and Registry

## Overview

The Game Settings Screen (`ULyraSettingScreen`) and Game Settings Registry (`ULyraGameSettingRegistry`) form the entry layer of Lyra's settings system. The settings screen handles display and interaction, while the registry manages all settings registration, filtering, and change tracking.

## Settings Screen Architecture

```
ULyraSettingScreen
  ├── TopSettingsTabs (ULyraTabListWidgetBase) — Tab switching
  ├── Settings_Panel (UGameSettingPanel) — Settings panel
  └── Bottom input bar — Back/Apply/Cancel
```

### Input Bindings

Three core input bindings are registered in `NativeOnInitialized`:

| Binding | Input Action | Description |
|------|---------|------|
| BackHandle | BackInputActionData | Back (confirms if changes exist) |
| ApplyHandle | ApplyInputActionData | Apply changes |
| CancelChangesHandle | CancelChangesInputActionData | Cancel changes |

### Dirty State Management

`OnSettingsDirtyStateChanged` dynamically adds/removes action buttons based on whether there are unsaved changes:

```
bSettingsDirty = true → AddActionBinding(ApplyHandle) + AddActionBinding(CancelChangesHandle)
bSettingsDirty = false → RemoveActionBinding(ApplyHandle) + RemoveActionBinding(CancelChangesHandle)
```

## Registry Creation

```
ULyraSettingScreen::CreateRegistry()
  └── NewRegistry = NewObject<ULyraGameSettingRegistry>()
        └── NewRegistry->Initialize(LocalPlayer)

UGameSettingScreen::GetOrCreateRegistry()
  └── CreateRegistry() [virtual function, implemented by subclass]
        ├── Bind OnSettingChangedEvent
        ├── Settings_Panel->SetRegistry(NewRegistry)
        └── Cache to Registry member variable
```

## Tab-Content Linkage Flow

```
1. Blueprint: Construct → RegisterTopLevelTab → RegisterDynamicTab(FLyraTabDescriptor)
2. RegisterDynamicTab → PendingTabLabelInfoMap.Add → RegisterTab(...)
3. TabButtonGroup automatically selects the first button (bSelectionRequired = true)
4. Click → SetSelectedInternal(true) → NativeOnSelected → Broadcast
5. HandleTabButtonSelected → Switch content + Broadcast OnTabSelected
6. Blueprint OnTabSelected → NavigateToSetting(SettingDevName)
      └── FindSettingByDevNameChecked
            └── FilterState.AddSettingToRootList(Setting)
                  └── Settings_Panel->SetFilterState(FilterState)
```

## FGameSettingRegistryChangeTracker

- **WatchRegistry**: Listen for setting changes in the registry
- **ApplyChanges**: Apply all dirty settings
- **RestoreToInitial**: Restore to initial state
- **ClearDirtyState**: Clear dirty state
- **DirtySettings**: Dirty setting map (TMap<FObjectKey, TWeakObjectPtr<UGameSetting>>)
- **bRestoringSettings**: Restoring flag, prevents recursion
