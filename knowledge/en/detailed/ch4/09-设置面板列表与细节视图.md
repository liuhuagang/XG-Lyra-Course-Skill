# Settings Panel, List, and Detail View

## Overview

The display layer of the settings panel consists of three core components: `UGameSettingPanel` (panel container), `UGameSettingListView` (settings list), and `UGameSettingDetailView` (settings detail view). These three work together to enable browsing, selecting, and editing settings.

## GameSettingPanel Responsibilities

### Panel Management

1. **Host settings list**: Holds `ListView_Settings` to display settings
2. **Host detail panel**: Holds `Details_Settings` to show details of the currently selected setting
3. **Event relay**: Relays three types of registry events (navigation, named actions, edit condition changes)

### Filter

`SetFilterState(const FGameSettingFilterState& InFilterState, bool bClearNavigationStack)`:
- Sets the panel's filter state
- Optional navigation stack management
- Automatically triggers list refresh

### Refresh Logic

```
RefreshSettingsList():
  ├── Re-entrancy guard (check RefreshHandle)
  ├── Use FTSTicker to defer one frame
  │     ├── Registry->GetSettingsForFilter(FilterState, VisibleSettings)
  │     ├── ListView_Settings->SetListItems(VisibleSettings)
  │     ├── NavigateToIndex(IndexToSelect) + SetSelectedIndex(IndexToSelect)
  │     └── Refresh edit state of all visible settings
  └── Clean RefreshHandle
```

### Hover/Selection Linkage

```
NativeOnInitialized:
  └── Bind ListView events
        ├── OnItemIsHoveredChanged → HandleSettingItemHoveredChanged → FillSettingDetails
        └── OnItemSelectionChanged → HandleSettingItemSelectionChanged → FillSettingDetails
        └── Forward to Details_Settings->FillSettingDetails
```

### Registry Events

| Event | Handler | Description |
|------|---------|------|
| OnSettingEditConditionChangedEvent | HandleSettingEditConditionsChanged | Re-evaluate visibility when edit conditions change, refresh list if needed |
| OnSettingNamedActionEvent | HandleSettingNamedAction | Named action events, broadcast to Blueprint |
| OnExecuteNavigationEvent | HandleSettingNavigation | Navigation events, create new filter and push onto navigation stack |

### Navigation Stack

```
HandleSettingNavigation:
  ├── FilterNavigationStack.Push(FilterState) — Save current state
  ├── Create new filter: NewPageFilterState.AddSettingToRootList(Setting)
  └── SetFilterState(NewPageFilterState, false) — Don't clear navigation stack

PopNavigationStack():
  └── Restore previous FilterState from navigation stack
```

## GameSettingListView Responsibilities

### Widget Type Mapping

Maps game settings to concrete widget Blueprint classes via `UGameSettingVisualData`:

```
OnGenerateEntryWidgetInternal:
  ├── VisualData->GetEntryForSetting(SettingItem)
  │     ├── Custom logic (virtual function GetCustomEntryForSetting)
  │     ├── Name lookup (EntryWidgetForName)
  │     └── Class inheritance chain lookup (EntryWidgetForClass)
  ├── GenerateTypedEntry<UGameSettingListEntryBase>
  ├── Name override
  └── EntryWidget.SetSetting(SettingItem)
```

### UGameSettingVisualData Lookup Priority

1. `GetCustomEntryForSetting` (virtual function, subclass customization)
2. `EntryWidgetForName.FindRef(DevName)` (by name)
3. `EntryWidgetForClass.FindRef(SettingClass)` (by class inheritance chain, traversing from subclass to parent)

## GameSettingDetailView Responsibilities

### Detail Panel Population

```
FillSettingDetails(UGameSetting* InSetting):
  ├── Duplicate request guard (check CurrentSetting)
  ├── Set setting name, description text
  ├── Dynamic detail text (visibility control)
  ├── Warning text (with <Icon.Warning> formatting)
  ├── Disabled reason text (iterate EditableState.GetDisabledReasons)
  └── Create extension sub-widgets
        ├── Hosted via Box_DetailsExtension
        ├── Managed using ExtensionWidgetPool
        └── Supports async loading (via UAssetManager::RequestAsyncLoad)
```

### Bound Widgets

| Widget | Type | Description |
|------|------|------|
| Text_SettingName | UCommonTextBlock | Setting name |
| RichText_Description | UCommonRichTextBlock | Setting description |
| RichText_DynamicDetails | UCommonRichTextBlock | Dynamic details |
| RichText_WarningDetails | UCommonRichTextBlock | Warning |
| RichText_DisabledDetails | UCommonRichTextBlock | Disabled reason |
| Box_DetailsExtension | UVerticalBox | Extension sub-widget container |

  └── UGameSettingValue (value-type settings)
