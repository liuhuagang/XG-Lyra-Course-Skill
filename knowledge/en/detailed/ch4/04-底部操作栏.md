# Bottom Action Bar

## Overview

The Bottom Action Bar is a component in Lyra's UI for displaying persistent action buttons. It is based on CommonUI's `UCommonBoundActionBar` system, automatically collecting and displaying registered action buttons through the UIActionBinding mechanism.

## Core Classes

### UCommonBoundActionBar (Container)

- **Responsibility**: Automatically collects all registered UIActionBindings and displays corresponding buttons in the action bar
- **Child Widget**: `W_BottomActionBar` (Blueprint)

### UCommonBoundActionButton (Button Base)

- **Responsibility**: Base class for individual action buttons in the action bar
- **Child Widget**: `W_BoundActionButton` (Blueprint)

### ULyraBoundActionButton

- **Header**: [LyraBoundActionButton.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/UI/Common/LyraBoundActionButton.h)
- **Inheritance**: `UCommonBoundActionButton` → `ULyraBoundActionButton`
- **Responsibility**: Lyra's action button implementation, supports input method style switching

## Registration Methods

Action buttons can be registered in two ways:

### Method 1: Class Defaults Toggle

Check options in the Widget's Class Defaults:
- **"Is Back Handler"**: Mark as back handler
- **"Is Back Action Displayed"**: Display in the action bar

### Method 2: C++ Code Registration

```cpp
RegisterUIActionBinding(FBindUIActionArgs(InputActionData, true, ...));
```

The second parameter `true` indicates the action should be displayed in the action bar.

## Input Method Style Switching

`ULyraBoundActionButton` supports switching button styles based on the current input device:
- **KeyboardStyle**: Style for keyboard/mouse input
- **GamepadStyle**: Style for gamepad input
- **TouchStyle**: Style for touch input

Input device changes are detected via the `HandleInputMethodChanged` event.
