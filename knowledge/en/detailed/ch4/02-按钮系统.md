# Button System

## Overview

Lyra's button system uses `ULyraButtonBase` as the core base class, providing unified button appearance and behavior management. In UE5.4+, button style management has been migrated from Blueprints to internal C++ implementation.

## Core Classes

### ULyraButtonBase

- **Header**: [LyraButtonBase.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/UI/Foundation/LyraButtonBase.h)
- **Inheritance**: `UCommonButtonBase` → `ULyraButtonBase`
- **Responsibility**: Project-wide common button base class

### Button States

- **Normal**: Default state
- **Selected**: Selected state (for toggle buttons)
- **Disabled**: Disabled state

## UE5.4+ Button Internal Changes

In UE5.4+, the internal implementation of `UCommonButtonBase` underwent significant changes:

- Button style management migrated from Blueprints (ButtonStyle reference) to internal C++ management
- Appearance switching controlled at the C++ level via the `SetButtonStyle()` internal method
- Button state switching is now entirely C++ driven

## Button Types

- **Normal Button**: Single click trigger, no state persistence
- **Toggleable Button**: Supports pressed/released state persistence
- **Action Button**: Bound to a specific UIAction, such as Back, Apply, Cancel, etc.
