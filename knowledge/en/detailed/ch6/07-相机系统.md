# Camera System

## Overview

Lyra's camera system consists of three layers: camera component, camera mode stack, and camera manager. It supports multi-mode switching, blend transitions, and UI camera overlay.

## Core Class Hierarchy

```
ALyraPlayerCameraManager (APlayerCameraManager)
  └── Manages overall camera behavior, camera shake, FOV

ULyraCameraComponent (UActorComponent) — CameraMode host
  ├── ULyraCameraModeStack — Camera mode stack
  │     ├── ULyraCameraMode_ThirdPerson — Third person mode
  │     └── [Other CameraMode] — Extensible
  └── Blend/overlay/penetration handling

ULyraUICameraManagerComponent (UActorComponent) — UI camera
  └── Independent camera for UI overlays
```

## ULyraCameraComponent

### Responsibilities

- Holds `ULyraCameraModeStack` instance
- Provides `GetCameraMode()`, `ChangeCameraMode()`, `AddCameraMode()` and other interfaces
- Computes final camera parameters (location, rotation, FOV) each frame
- Handles camera penetration avoidance (delegates to CameraMode's penetration detection)
- Implements `ILyraCameraAssistInterface` for other systems to query camera state

### InitState Participation

CameraComponent also participates in the init state machine:

- `RegisterInitStateFeature()` registers
- Waits for PawnExtension to reach DataAvailable
- Creates CameraModeStack during DataAvailable → DataInitialized phase

### Key Methods

```cpp
void GetCameraView(float DeltaTime, FMinimalViewInfo& DesiredView);
void ChangeCameraMode(const FGameplayTag& ModeTag);
void AddCameraMode(const FGameplayTag& ModeTag, float BlendTime);
void ClearCameraMode();
```

## ULyraCameraMode

`ULyraCameraMode` is the base class for camera modes, defining the standard interface for camera computation.

### Key Properties

```cpp
// Camera mode Tag (for identification and lookup)
FGameplayTag CameraModeTag;

// Field of view
float FieldOfView;

// Post-process settings
FPostProcessSettings PostProcessBlendSettings;
float PostProcessBlendWeight;

// Blending
float BlendTime;        // Transition time into this mode
float BlendAlpha;       // Current blend alpha
EAlphaBlendOption BlendFunction; // Blend function

// Penetration avoidance
FLyraPenetrationAvoidanceFeeler PenetrationAvoidanceFeeler;
```

### Core Methods

```cpp
virtual void UpdateCamera(float DeltaTime, FCameraModeView& OutView);
virtual void UpdateView(float DeltaTime, FCameraModeView& OutView);
virtual void UpdatePrecalcs(float DeltaTime);
void GetCameraModeView(FMinimalViewInfo& DesiredView, float DeltaTime);
```

### FCameraModeView

```cpp
struct FCameraModeView {
    FVector Location;
    FRotator Rotation;
    float FieldOfView;
};
```

## ULyraCameraModeStack

The camera mode stack manages mode push/pop/blending.

### Stack Operations

```cpp
void PushMode(TSubclassOf<ULyraCameraMode> ModeClass);   // Push to stack
void PopMode(TSubclassOf<ULyraCameraMode> ModeClass);    // Pop from stack
void EvaluateStack(float DeltaTime, FCameraModeView& OutView);  // Evaluate each layer
void BlendStack(FCameraModeView& OutView);               // Blend all layers
```

### Blend Strategy

1. Evaluate each CameraMode's `FCameraModeView` from bottom to top of the stack
2. Use blend alpha (BlendAlpha) for smooth transitions between adjacent layers
3. Supports multiple blend functions (Linear, Cubic, HermiteCubic, Sinusoidal, QuadraticInOut, CubicInOut, HermiteCubicInOut, QuarticInOut, QuinticInOut, CircularIn, CircularOut, CircularInOut, ExpIn, ExpOut, ExpInOut, Custom)

### Layered Overlay

CameraMode stack blending computes each layer independently then overlays them by weight, rather than simple replacement. This allows multiple camera effects to coexist (e.g., aim zoom + camera shake).

## ULyraPlayerCameraManager

Inherits from `APlayerCameraManager`, the default camera manager for PlayerController.

### Key Overrides

- Initializes CameraComponent on creation
- Overrides `UpdateCamera` to use CameraComponent's computed results
- Handles camera shake
- Manages FOV and PostProcess settings

## ULyraUICameraManagerComponent

Provides an independent camera view for UI, preventing the UI camera from being overwritten by the game camera.

- Runs independently from the main camera system
- Used for UI transition animations, loading screens, menus, etc.

## ILyraCameraAssistInterface

```cpp
interface ILyraCameraAssistInterface {
    virtual void GetCameraView(float DeltaTime, FMinimalViewInfo& DesiredView) = 0;
    virtual bool IsFeathering() const { return false; } // Whether in feathering state
};
```

- Implemented by ULyraCameraComponent
- Allows other systems (AI, animation, Ability) to query current camera state

## Camera System Data Flow

```
Per-frame update:
  ALyraPlayerCameraManager::UpdateCamera
    → ULyraCameraComponent::GetCameraView
      → ULyraCameraModeStack::EvaluateStack
          → ULyraCameraMode::UpdateCamera (per layer)
              → ULyraCameraMode::UpdateView (subclass implementation)
              → Penetration avoidance (PenetrationAvoidance)
          → ULyraCameraModeStack::BlendStack (blend all layers)
      → Returns FMinimalViewInfo
    → APlayerCameraManager applies final view
```
