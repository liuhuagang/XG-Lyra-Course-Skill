# Input System

## Overview

Lyra's input system is built on UE5's Enhanced Input framework, providing declarative input binding through `ULyraInputComponent` and `ULyraInputConfig`, mapping input actions to GameplayAbilities.

## Core Classes

| Class | Base Class | Responsibility |
|----|------|------|
| `ULyraInputComponent` | `UEnhancedInputComponent` | Extra InputAction binding and Tag query |
| `ULyraInputConfig` | `UDataAsset` | Input config data asset, defines Tag→InputAction mapping |
| `ULyraInputModifiers` | `UInputModifier` | Input modifier series (sensitivity, axis inversion, etc.) |
| `ULyraInputUserSettings` | `UEnhancedInputUserSettings` | User input settings (key mapping config) |
| `ULyraPlayerMappableKeyProfile` | `UEnhancedPlayerMappableKeyProfile` | Key mapping profile |

## ULyraInputComponent

```cpp
class ULyraInputComponent : public UEnhancedInputComponent
```

- Inherits from `UEnhancedInputComponent`, adds `ULyraInputConfig` reference
- Provides `TArray<uint32> TaggedBindings` for tracking tag-bound inputs
- `AddTaggedBinding`/`RemoveTaggedBinding` manages binding lifecycle

## ULyraInputConfig

```cpp
UCLASS(BlueprintType)
class ULyraInputConfig : public UDataAsset
{
    GENERATED_BODY()
public:
    UPROPERTY(EditDefaultsOnly, BlueprintReadOnly)
    TArray<FLyraInputAction> AbilityInputActions;

    UPROPERTY(EditDefaultsOnly, BlueprintReadOnly)
    TArray<FLyraInputAction> NativeInputActions;

    // Core binding method
    void BindAbilityActivation(ULyraInputComponent* InputComponent,
                               ULyraAbilitySystemComponent* ASC) const;
};
```

### FLyraInputAction

```cpp
USTRUCT(BlueprintType)
struct FLyraInputAction {
    UPROPERTY(EditDefaultsOnly, BlueprintReadOnly)
    UInputAction* InputAction;      // Enhanced Input Action asset

    UPROPERTY(EditDefaultsOnly, BlueprintReadOnly, Meta = (Categories = "InputTag"))
    FGameplayTag InputTag;          // Corresponding GameplayTag
};
```

### Binding Flow

```
ULyraHeroComponent::OnSetupInputComponents
  └── ULyraInputConfig::BindAbilityActivation(InputComponent, ASC)

BindAbilityActivation:
  for (FLyraInputAction InputAction : AbilityInputActions)
  {
    FGameplayAbilitySpecHandle AbilityHandle =
        ASC->BindAbilityActivationToInputComponent(
            InputComponent,
            FGameplayAbilityInputBinds(/* config */));

    InputComponent->BindAction(InputAction.InputAction, ETriggerEvent::Triggered,
        /* callback */);
  }
```

### Event Types

- `AbilityInputActions` — Bound to GameplayAbility, handled automatically by ASC for activation/cancel
- `NativeInputActions` — Bound to native C++ callbacks, for non-GAS input handling

## Input Modifiers

A series of input modifiers defined in `LyraInputModifiers.h`:

| Modifier | Function |
|--------|------|
| `ULyraSettingBasedScalar` | Setting-based scalar modifier, reads sensitivity from `ULyraSettingsLocal` |
| `ULyraInputModifierAimInversion` | Aim axis inversion modifier |
| `ULyraInputModifierGamepadSensitivity` | Gamepad sensitivity modifier |

## Input User Settings

- `ULyraInputUserSettings` inherits from `UEnhancedInputUserSettings`
- Manages `UInputMappingContext` registration and priority
- Handles `UEnhancedPlayerMappableKeyProfile` key configurations

## Data Assets

- `ULyraAimSensitivityData`: Sensitivity preset data asset, configures multipliers for different aim types

## Typical Configuration

```
InputConfig (DataAsset)
  ├── AbilityInputActions:
  │     ├── IA_Jump → InputTag.Action.Jump
  │     ├── IA_Fire → InputTag.Action.Fire
  │     ├── IA_Aim  → InputTag.Action.Aim
  │     └── ...
  └── NativeInputActions:
        ├── IA_Escape → InputTag.Action.Escape (Open menu)
        └── ...
```

## Input Binding Pipeline Summary

```
PlayerController Created
  → ULyraHeroComponent::OnSetupInputComponents
    → Creates ULyraInputComponent
    → Reads ULyraInputConfig from PawnData
    → InputConfig->BindAbilityActivation
      → ASC->BindAbilityActivationToInputComponent (GA binding)
      → InputComponent->BindAction (Native binding)
```
