# Main Animation Blueprint State Machine

## Overview

The state machine (AnimGraph) of the main animation blueprint is the core scheduling structure of the Lyra Locomotion system, managing transitions between basic movement states such as walk, run, jump, fall, stop, and pivot. Corresponds to course number 075, with specific editor interface screenshots in the [original .docx lecture](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/docs/UE5_Lyra学习指南_075_构建主动画蓝图状态机.docx).

## State Machine Architecture

```
AnimGraph (Main Animation Blueprint)
  └── Locomotion (Listens to animation layer changes)
        ├── Idle — Idle
        ├── Start — Start
        ├── Cycle — Cycle (walk/run)
        ├── Stop — Stop
        ├── Pivot — Pivot
        └── Jump
              ├── JumpStart
              ├── JumpApex
              ├── FallLoop
              └── FallLand
```

## Detailed State Breakdown

### Idle

- `UpdateIdleState`:
  - If blending out, set turn curve value to 0
  - If not blending out, accumulate turn values and reduce the turn value consumed by animation

### Start

- `SetUpStartState` — Selects start animation, initializes parameters
- `UpdateStartState` — Advances animation playback

**Transition Conditions (Start → Cycle):**
- Auto transition
- State speed transition
- Animation layer change transition
- Turn angle transition

### Cycle

- Walk/run/jump cycle animations
- Specific pose data provided by animation layer blueprints

### Stop

- `UpdateStopState` — Updates stop animation playback

**Transition Conditions:**
- Cycle → Stop: State speed determination
- Stop → Start: Acceleration determination
- Stop → Idle: Largely similar logic

### Pivot

- `SetUpPivotState` — Sets up pivot animation, initializes parameters
- `UpdatePivotState` — Pivot animation time is set by the animation layer

**Transition Conditions (Pivot → Cycle):**
- Animation layer change
- Movement state change
- Animation notification

**Pivot Trigger:** `PivotSources → Pivot`

### Jump

- **JumpStart** — Jump start
- **JumpApex** — Jump apex
- **FallLoop** — Fall loop
- **FallLand** — Landing

> The conditions are relatively straightforward; note the alias mapping for each state.

## State Machine & Animation Layer Relationship

The state machine handles state scheduling, but some logic is configured as callbacks in the animation layer blueprints. The main animation blueprint interacts with animation layers through **Linked Anim Layers**:

```
State Machine Scheduling (Main Animation Blueprint)
  ↓ State change notification
Animation Layer Response (Animation Layer Blueprint)
  ↓ Pose data return
State Machine Application (Main Animation Blueprint)
```
