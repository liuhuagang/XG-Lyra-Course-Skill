# Movement System & Acceleration Replication

## ULyraCharacterMovementComponent

`ULyraCharacterMovementComponent` inherits from `UCharacterMovementComponent` and is injected by `ALyraCharacter` via `SetDefaultSubobjectClass` in the constructor.

## Acceleration Replication

### Data Structure

```cpp
struct FLyraReplicatedAcceleration {
    uint8 AccelXYRadians;   // Horizontal direction angle [0, 255], quantized from Cartesian→Polar
    uint8 AccelXYMagnitude; // Horizontal magnitude [0, 255]
    int8  AccelZ;           // Vertical component [-127, 127]
};
```

### Replication Pipeline

```
Server
  ALyraCharacter::PreReplication()
    → CartesianToPolar(FVector) → Quantize → FLyraReplicatedAcceleration

Replication Condition
  DOREPLIFETIME_CONDITION(ReplicatedAcceleration, COND_SimulatedOnly)

Client
  ALyraCharacter::OnRep_ReplicatedAcceleration()
    → PolarToCartesian → FVector
    → ULyraCharacterMovementComponent::SetReplicatedAcceleration(FVector)
```

### SimulateMovement Override

```cpp
void ULyraCharacterMovementComponent::SimulateMovement(float DeltaTime)
{
    // If acceleration replication is enabled, apply replicated acceleration first
    if (bHasReplicatedAcceleration)
    {
        // Drive simulated movement with replicated acceleration
        Acceleration = ReplicatedAcceleration;
    }
    Super::SimulateMovement(DeltaTime);
}
```

## Engine Acceleration Replication Mechanism

- CVar `p.EnableCharacterAccelerationReplication`: Enables/disables engine-level acceleration replication
- `ACharacter::ShouldReplicateAcceleration()`: Determines whether to replicate acceleration
- `ACharacter::GatherCurrentMovement()`: Collects current acceleration data

## Tag-Controlled Movement

`ULyraCharacterMovementComponent` controls character movement through GameplayTags:

```cpp
FRotator ULyraCharacterMovementComponent::GetDeltaRotation(float DeltaTime) const
{
    if (HasMatchingGameplayTag(TAG_Gameplay_MovementStopped))
        return FRotator(0, 0, 0);  // No rotation
    return Super::GetDeltaRotation(DeltaTime);
}

float ULyraCharacterMovementComponent::GetMaxSpeed() const
{
    if (HasMatchingGameplayTag(TAG_Gameplay_MovementStopped))
        return 0;  // No movement
    return Super::GetMaxSpeed();
}
```

## Ground Detection

```cpp
struct FLyraCharacterGroundInfo {
    uint64 LastUpdateFrame;   // Cached frame count
    FHitResult GroundHitResult; // Trace hit result
    float GroundDistance;       // Distance to ground
};
```

- `GetGroundInfo()` is frame-cached; repeated calls within the same frame do not re-trace
- GroundDistance = 0 in MOVE_Walking mode
- Other modes perform a line trace downward from capsule center minus half height, trace distance = `GroundTraceDistance + CapsuleHalfHeight`

## Movement Mode Packing (PackNetworkMovementMode)

```cpp
namespace PackedMovementModeConstants {
    const uint32 GroundShift = FMath::CeilLogTwo(MOVE_MAX); // 3
    const uint8 CustomModeThr = 2 * (1 << GroundShift);     // 16
    const uint8 GroundMask = (1 << GroundShift) - 1;        // 7
}

uint8 PackNetworkMovementMode() const
{
    if (MovementMode != MOVE_Custom) {
        const uint8 GroundModeBit = (GroundMovementMode == MOVE_Walking ? 0 : 1);
        return uint8(MovementMode.GetValue()) | (GroundModeBit << GroundShift);
    } else {
        return CustomMovementMode + CustomModeThr;
    }
}
```

- Low 3 bits: Main movement mode (Walking=1, Falling=2, Swimming=3, Flying=4, Custom=6)
- Bit 3: Ground movement mode bit (0=Walking, 1=NavWalking)
- Custom mode offset: `CustomMovementMode + 16`
