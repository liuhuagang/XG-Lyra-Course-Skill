# Third Person Camera & Penetration Handling

## ULyraCameraMode_ThirdPerson

Inherits from `ULyraCameraMode`, implementing third-person camera view computation and penetration avoidance.

## Core Parameters

```cpp
// Camera offset relative to character
FVector CameraOffset;           // Spatial offset (relative to target position)

// Aim offset
FVector AimOffset;              // Extra offset when aiming

// Distance
float TargetArmLength;           // Target arm length
float ArmOriginLagSpeed;         // Arm origin lag speed
float ArmOriginLagMaxDistance;   // Arm origin max lag distance

// Rotation
FRotator TargetRotation;         // Target rotation (controlled by input)
bool bUsePawnControlRotation;    // Use pawn control rotation

// Penetration Avoidance
bool bDoPenetrationAvoidance;    // Enable penetration avoidance
float PenetrationAvoidanceLagSpeed;  // Penetration retreat lag speed
```

## UpdateView Computation Flow

```
1. Determine camera pivot target
   └── Pawn position + AimOffset (if aiming offset exists)

2. Compute arm position
   └── Pivot Target + ArmLength × rotation direction (inverse)

3. Apply lag
   └── ArmOriginLagSpeed controls smooth speed of arm position change
   └── ArmOriginLagMaxDistance limits max lag distance

4. Penetration avoidance
   └── Collision detection from Pivot Target to camera position
   └── If obstructed by an object, push the camera forward

5. Apply CameraOffset
   └── Apply offset in camera local space

6. Compute FOV
   └── Distance from Pawn to camera affects FOV (optional)
```

## Penetration Avoidance

### FLyraPenetrationAvoidanceFeeler

```cpp
struct FLyraPenetrationAvoidanceFeeler {
    FRotator AdjustmentRot;     // Detection direction (rotation offset relative to camera orientation)
    float BackwardsDistance;     // Backward detection distance
    float ForwardDistance;       // Forward detection distance (optional)
};
```

- Multiple Feelers can be configured for different directions
- The detection process tries multiple directions to find an unblocked position
- Uses `World->SweepMultiByChannel(OutHits, ...)` for collision detection

### Avoidance Algorithm

```
1. Sweep from PivotTarget to ideal camera position
2. If obstruction detected:
   a. Try other directions according to PenetrationAvoidanceFeeler config
   b. Do collision detection for each direction in sequence
   c. Find the first unobstructed direction
   d. Use PenetrationAvoidanceLagSpeed to smoothly transition to new camera position
3. If no obstruction:
   └── Use the computed camera position normally
```

### Camera Penetration Avoidance Collision Query

```
Collision Channel: Camera (ECC_GameTraceChannel2)
Response: Block world static/dynamic geometry, ignore Pawn itself
```

## UCameraMode Blending

The third-person camera mode typically serves as the base layer in the CameraModeStack, with other modes (e.g., aiming mode) overlaid on top:

```
CameraModeStack (Base):
  [0] ULyraCameraMode_ThirdPerson (Base third person)
  [1] ULyraCameraMode_Aiming (Aim zoom, overlaid on third person)
```

- The base layer provides position/rotation/FOV during blending
- Overlay layers make adjustments on top of the base layer
