# Animation Concept Reference

## Overview

This reference table lists Unreal Engine professional animation concepts involved in the Lyra animation system (corresponding to course number 077), with UE official documentation marked for further reading.

## Concept List

| Concept | Description | Official Documentation Reference |
|------|------|--------------|
| Animation Node Function | Node functions in Animation Blueprint for encapsulating animation logic | Engine Docs > Animation Nodes |
| Property Access | Ways to access character properties in animation blueprints | Engine Docs > Animation Blueprint Properties |
| Blend Nodes | Blend Nodes, used to blend multiple animation poses | Engine Docs > Animation Blending |
| Pose Warping | Dynamically adjusts bone poses to match targets | Engine Docs > Pose Warping |
| Distance Matching | Matches animation playback progress based on movement distance | Engine Docs > Distance Matching |
| Hand IK | Hand IK, hand-to-object/weapon interaction positioning | Engine Docs > IK |
| Two Bone IK | Two Bone IK, inverse kinematics solving for three-joint chains | Engine Docs > Two Bone IK |
| Copy Bone | Copies bone transforms from one bone to another | Engine Docs > Copy Bone Node |
| Transform Bone | Directly sets bone position/rotation/scale | Engine Docs > Transform Bone Node |
| Virtual Bone | Creates virtual reference points in animation blueprints | Engine Docs > Virtual Bones |

## Animation Blueprint Node Categories

| Category | Common Nodes |
|------|---------|
| Blending | Blend Poses By Bool, Blend Poses By Int, Layered blend per bone, Blend Space |
| Skeletal Control | Two Bone IK, Hand IK, Copy Bone, Transform Bone, Fabrik |
| Posing | Pose Warping, Distance Matching |
| Utilities | Virtual Bone, Linked Anim Graph, State Machine |

## Usage Suggestions

The above concepts are applied in both the animation layer blueprint (ABP_ItemAnimLayersBase) and the main animation blueprint (ABP_Mannequin_Base). It is recommended to understand them in the editor alongside the actual animation blueprint node configuration.
