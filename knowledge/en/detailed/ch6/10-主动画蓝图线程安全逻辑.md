# Main Animation Blueprint Thread-Safe Logic

## Overview

The thread-safe update function (`BlueprintThreadSafeUpdateAnimation`) of the main animation blueprint executes on the animation worker thread without blocking the game thread. This portion is responsible for data preparation and state computation, providing the data foundation for the subsequent animation blueprint state machine and animation layers. Corresponds to course number 074, with specific editor interface screenshots in the [original .docx lecture](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/docs/UE5_Lyra学习指南_074_构建主动画蓝图线程安全逻辑.docx).

## Core Functions

### GetMainAnimBPThreadSafe

- Must successfully obtain the main animation blueprint reference
- Animation layers need to read large amounts of data from the main animation blueprint

### UpdateBlendWeightData

- Updates blend weight data
- Provides weight inputs for blend transitions of each animation layer

### Aim/Shoot Offset Control

**Conditions for using aim shoot offset (no hipfire blending):**
- Crouching and not having "raise weapon after firing while crouched" enabled
- Not crouching, currently aiming, and character is on the ground

**Conditions for using aim shoot offset (with hipfire blending):**
- Time since last fire is less than "raise weapon after firing" time
- Aiming while crouching or not on the ground
- Animation curve value `applyHipfireOverridePose > 0`

**Conditions for dynamically reducing hipfire blend:**
- Character is moving with low root offset, reducing aim shoot offset degree

### UpdateJumpFallData

- Reads main animation blueprint state, computes fall time
- Provides data for jump/fall states

### UpdateSkelControlData

- Controls IK blend amount based on animation curve values and bools
- Manages skeletal controller weights

## Data Flow

```
BlueprintThreadSafeUpdateAnimation (Worker Thread)
  ├── GetMainAnimBPThreadSafe — Get main animation blueprint
  ├── UpdateBlendWeightData — Update blend weights
  ├── Aim offset condition check — Control aim/hipfire blend
  ├── UpdateJumpFallData — Jump/fall data
  └── UpdateSkelControlData — IK controller weights
        ↓
Animation Blueprint State Machine (Game Thread)
        ↓
Animation Layer Blueprint (Game Thread)
```
