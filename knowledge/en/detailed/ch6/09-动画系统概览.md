# Animation System Overview

## Overview

Lyra's animation system is built around the Locomotion framework, including physics assets, post-process animations, FootIK, animation blueprint hierarchy, animation layer interfaces, and other structures. This section corresponds to course number 071, where UI operation screenshots are provided by the [original lecture](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/docs/UE5_Lyra学习指南_071_动画系统.docx).

> Note: The course instructor is not a professional animation TA; explanations of the Locomotion animation system are for reference only.

## Animation Asset Architecture

```
Skeletal Mesh
  ├── LOD assets (configured per platform independently)
  ├── Ghost settings (ghost/trail effects, enabled on skeletal mesh)
  └── Physics asset
        └── Custom physical materials (hit detection Tag, weak spot damage)

Post-process Animations
  ├── ABP_Manny_PostProcess — Limits excessive deformation
  ├── CR_Mannequin_Procedural — Bone swing/rotation transfer computation
  └── CR_Mannequin_FootPlant — FootIK

IK System
  ├── IK_Mannequin — IK Rig asset
  └── IK Retargeter — IK retargeting asset

Copy/Retarget Blueprints
  ├── ABP_Mannequin_CopyPose — Copy pose
  └── ABP_Mannequin_Retarget — Retarget pose

Main Animation Blueprints
  ├── ABP_Mannequin_Base — Main Locomotion animation blueprint
  └── ABP_Mannequin_TopDown — Top-down animation blueprint

Animation Layers
  ├── ALI_ItemAnimLayers — Animation layer interface
  └── ABP_ItemAnimLayersBase — Specific animation layer logic

Locomotion Configs
  ├── Pistol/Rifle/Shotgun/Unarmed — Per-weapon configs
  └── Configure animation assets only
```
