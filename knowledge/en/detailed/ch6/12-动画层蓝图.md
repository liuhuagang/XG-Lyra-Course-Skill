# Animation Layer Blueprint

## Overview

Animation Layer Blueprints implement the internal complex logic of specific animation layers, connecting to the main animation blueprint through a Layer Interface. Lyra uses `ALI_ItemAnimLayers` as the interface and `ABP_ItemAnimLayersBase` as the implementation. Corresponds to course number 076, with specific editor interface screenshots in the [original .docx lecture](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/docs/UE5_Lyra学习指南_076_构建动画层蓝图.docx).

## Architecture Hierarchy

```
FullBody
  ├── FullBody_IdleState — Idle state
  │     ├── Idle Break
  │     ├── Turn In Place
  │     └── Turn In Place Recovery
  ├── FullBody_StartState — Start state
  ├── FullBody_CycleState — Cycle state
  ├── FullBody_StopState — Stop state
  ├── FullBody_PivotState — Pivot state
  ├── FullBody_JumpStartLoopState — Jump start loop
  ├── FullBody_JumpStartState — Jump start
  ├── FullBody_JumpApexState — Jump apex
  ├── FullBody_FallLoopState — Fall loop
  └── FullBody_FallLandState — Land

LeftHandPose_OverrideState — Left hand pose override

FullBody_SkeletalControls — Skeletal controls (IK)

FullBody_Aiming — Aiming pose

FullBodyAdditives — Additive animation layer
```

## Detailed Sub-State Breakdown

### IdleState

**Idle Break:**
- Establishes break time (countdown mechanism)
- Transition condition `Idle → IdleBreak`: Triggered when countdown reaches zero
- Selects break animation: Randomly picks from preset animations

**Turn In Place:**
- `SetupTurnInplaceAnim` — Resets animation advance time
- `SetUpTurnInPlaceRotationState` — Gets turn direction
- `UpdateTurnInPlaceAnim` — Updates animation advancing the turn

**Turn In Place Recovery:**
- Enters recovery state when transition condition is met
- Restores playback time position
- Eventually enters Idle state or triggers another rotation

### StartState

- `SetupStartAnim` — Selects start animation, resets parameters
- `UpdateStartAnim` — Advances animation playback time, computes stride Alpha value, selects animation playback time based on distance
- `UpdateHipFireRaiseWeaponPose` — Blends in hipfire animation

> This part involves techniques such as Pose Warping and Distance Matching

### CycleState

Continuously plays walking/running cycle animations, driven by speed.

### StopState

- `SetUpStopAnim` — When current speed exists but no acceleration, matches speed to 0
- `UpdateStopAnim` — Advances stop animation

### PivotState

- `SetUpPivotAnim` — Sets up pivot animation selection, initializes parameters
- `UpdatePivotAnim` — First decelerates then accelerates based on pivot progress, matching different animation advance modes

### Jump/Fall State Sequence

```
JumpStartLoop → JumpStart → JumpApex → FallLoop → FallLand
```

Each state advances sequentially along the jump/fall lifecycle.

### SkeletalControls

Controls IK blend amount based on animation curve values and bools.

## Animation Layer & Main Animation Blueprint Collaboration

```
Main Animation Blueprint State Machine
  ↓ State change
Animation Layer Blueprint (ABP_ItemAnimLayersBase)
  ↓ Pose computation
Returns data via Animation Layer Interface (ALI_ItemAnimLayers)
  ↓
Main Animation Blueprint applies final pose
```
