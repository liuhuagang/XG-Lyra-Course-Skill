# Character Class Hierarchy

## Class Hierarchy

```
AModularPawn (Engine)
  └── ALyraPawn : ILyraTeamAgentInterface  — Base Pawn, not used in the project

AModularCharacter (Engine)
  └── ALyraCharacter : IAbilitySystemInterface, IGameplayCueInterface,
                        IGameplayTagAssetInterface, ILyraTeamAgentInterface  — Main character class
        └── ALyraCharacterWithAbilities  — Self-contained ASC, not used in the project
```

- `ALyraPawn` inherits from `AModularPawn` (GameFrameworkComponentManager integration) and `ILyraTeamAgentInterface`, providing basic team ID replication and team propagation during PossessedBy/UnPossessed
- The project actually uses `ALyraCharacter`; `ALyraPawn` and `ALyraCharacterWithAbilities` serve as references but are not used

## ALyraCharacter Interface Implementations

### IAbilitySystemInterface

```cpp
UAbilitySystemComponent* ALyraCharacter::GetAbilitySystemComponent() const
{
    // Delegates to PawnExtensionComponent
    return PawnExtComponent ? PawnExtComponent->GetLyraAbilitySystemComponent() : nullptr;
}
```

- `ALyraCharacter` does not hold an ASC directly; it indirectly accesses it through PawnExtensionComponent

### IGameplayTagAssetInterface

All four methods delegate to ASC:

```cpp
void GetOwnedGameplayTags(FGameplayTagContainer& TagContainer) const { ASC->GetOwnedGameplayTags(TagContainer); }
bool HasMatchingGameplayTag(FGameplayTag Tag) const { return ASC->HasMatchingGameplayTag(Tag); }
bool HasAllMatchingGameplayTags(const FGameplayTagContainer& TagContainer) const { return ASC->HasAllMatchingGameplayTags(TagContainer); }
bool HasAnyMatchingGameplayTags(const FGameplayTagContainer& TagContainer) const { return ASC->HasAnyMatchingGameplayTags(TagContainer); }
```

### ILyraTeamAgentInterface (Team System)

- `ALyraCharacter` replicates `MyTeamID` (`COND_OwnerOnly`)
- `PossessedBy`: Gets Team ID from Controller
- `UnPossessed`: Calls `DetermineNewTeamAfterPossessionEnds` to re-determine Team ID
- `OnControllerChangedTeam`: Propagates Controller's Team change to Character
- Modifying Team ID requires: no Controller constraint + server authority

## ReplicatedAcceleration

```cpp
struct FLyraReplicatedAcceleration {
    uint8 AccelXYRadians;   // Horizontal direction angle quantized to [0, 255]
    uint8 AccelXYMagnitude; // Horizontal magnitude quantized to [0, 255]
    int8  AccelZ;           // Vertical component [-127, 127]
};
```

- `PreReplication`: Converts `FVector` from Cartesian→Polar coordinate format, quantizes to uint8/int8
- `OnRep_ReplicatedAcceleration`: Restores Polar→Cartesian and calls `SetReplicatedAcceleration`
- `DOREPLIFETIME_CONDITION(ReplicatedAcceleration, COND_SimulatedOnly)` — Replicates only to simulated proxies

## FastShared Replication

- `ULyraReplicationGraph::InitGlobalActorClassSettings` binds `FastSharedReplicationFunc`
- Server `UpdateSharedReplication` compares against `LastSharedReplication`, calls `FastSharedReplication(SharedMovement)` via `NetMulticast, unreliable` when changed
- `FSharedRepMovement` contains: RepMovement, RepTimeStamp, RepMovementMode, bProxyIsJumpForceApplied, bIsCrouched
- Client `FastSharedReplication_Implementation` updates timestamp, movement mode, location/rotation/velocity, jump force, crouch
- `bIsUsingFastSharedReplication` flag controls; client falls back to full update when receiving non-FastShared updates

## Death Flow

```
OnDeathStarted
  ├── DisableMovementAndCollision()
  │     ├── SetIgnoreMoveInput(true)
  │     ├── SetActorEnableCollision(false)
  │     ├── StopMovementImmediately()
  │     └── DisableMovement()
  └── [Delay] → OnDeathFinished

OnDeathFinished
  └── DestroyDueToDeath()
        ├── K2_OnDeathFinished() — BlueprintImplementableEvent
        └── UninitAndDestroy()
              ├── DetachFromControllerPendingDestroy()
              ├── SetLifeSpan(0.1f)
              ├── ASC cleanup
              └── SetActorHiddenInGame(true)
```

- `OnDeathStarted` disables movement and collision
- `OnDeathFinished` executes destruction flow, destroys after 0.1 seconds
- `FellOutOfWorld` calls `HealthComponent->DamageSelfDestruct(true)` to trigger suicide

## Movement Mode Tag System

- `MovementModeTagMap` maps `EMovementMode` to `FGameplayTag`: Walking, NavWalking, Falling, Swimming, Flying, Custom
- `OnMovementModeChanged` clears old tag, sets new tag (`SetLooseGameplayTagCount`)
- Crouch: `OnStartCrouch` sets `Status_Crouching` tag, `OnEndCrouch` removes it
- `CanJumpInternal_Implementation` removes parent class crouch check

## Constructor Configuration

- `SetDefaultSubobjectClass<ULyraCharacterMovementComponent>` to inject custom movement component
- Collision Profiles: `NAME_LyraCharacterCollisionProfile_Capsule`, `NAME_LyraCharacterCollisionProfile_Mesh`
- Movement Parameters: `MaxAcceleration=2400`, `BrakingFriction=6`, `GroundFriction=8`, `RotationRate=720`
- Creates sub-components: PawnExtComponent, HealthComponent, CameraComponent
