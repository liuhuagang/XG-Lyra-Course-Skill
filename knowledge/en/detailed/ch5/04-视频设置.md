# Video Settings

## Overview

Video settings are created by the `InitializeVideoSettings` function, located in `LyraGameSettingRegistry_Video.cpp`. `InitializeVideoSettings_FrameRates` additionally provides frame rate limit options. Video settings are the most complex settings collection, containing four sub-groups: Display, Graphics, Graphics Quality, and Advanced Graphics.

## AutoSetQuality Linkage

AutoSetQuality is a key edit dependency chain. When the user clicks "Auto Set Quality":

```
AutoSetQuality (UGameSettingAction)
  └── Execute action:
        ├── RunAutoBenchmark → ULyraSettingsLocal::RunAutoBenchmark()
        └── ResetToMobileDeviceDefaults
              │
              └── AddEditDependency affects:
                    ├── OverallQuality → Triggers EditConditionChanged on value update
                    ├── ResolutionScale → Recalculates edit state
                    ├── GlobalIllumination
                    ├── Shadows
                    ├── AntiAliasing
                    ├── ViewDistance
                    ├── Textures
                    ├── Effects
                    ├── Reflections
                    └── PostProcessing
```

Edit conditions for each rendering quality setting:

```
Is AutoSetQuality running? →
  ├── Yes → Disable all quality options (prevent manual changes conflicting with auto-detection)
  └── No → Check OverallQuality
        ├── Custom → Enable all quality options
        └── Non-Custom → Disabled (controlled uniformly by preset)
```

## Frame Rate Limits

`InitializeVideoSettings_FrameRates` populates frame rate limit options in the VideoCollection. Uses `FGameSettingEditCondition_FramePacingMode` to control option visibility based on platform type (MobileStyle/ConsoleStyle/DesktopStyle).
