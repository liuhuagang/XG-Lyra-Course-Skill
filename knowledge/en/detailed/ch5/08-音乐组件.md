# Music Component

## Overview

The Music Component is a Blueprint component system responsible for playing and managing background music in-game. It implements a dynamic music system via MetaSound, including combat intensity control and Fire Stinger event triggering.

## Architecture

The Music Component is a Blueprint class (not C++), attached to Pawns via the Experience loading flow.

| Class | Type | Description |
|----|------|------|
| `B_MusicManagerComponent_Base` | Blueprint | Base music management component |
| `B_MusicManagerComponent_FE` | Blueprint | Main menu specific variant |

## B_MusicManagerComponent_Base

### Core Features

| Feature | Description |
|------|------|
| Background Music Playback | Plays looping background music via MetaSound |
| Combat Intensity | 0~1 float value controlling music tension level |
| Fire Stinger | Short sound effect triggered by combat events |

### Combat Intensity System

- Combat intensity drifts toward 0 in non-combat states (natural decay)
- Set to 1 when entering combat
- Higher combat intensity lowers background music volume (making room for combat sound effects)

### Fire Stinger

- Triggered when combat events occur
- Short sound effect played on top of background music

## B_MusicManagerComponent_FE

- Main menu specific variant
- Modifies the "is in menu" MetaSound parameter
- Does not support the combat system

## MetaSound Integration

The Music Component controls music behavior through MetaSound parameters:

| Parameter | Description |
|------|------|
| Combat Intensity | Controls background music volume attenuation |
| is in menu | Controls main menu music state |

## Data Flow

```
Pawn (Audio Component attached via Experience)
  └── B_MusicManagerComponent_Base
        ├── Tick updates combat intensity drift
        ├── Combat event → Fire Stinger
        └── MetaSound parameter updates
              ├── Volume control
              └── State switching
```

## Notes

- Fully Blueprint-based implementation, no C++ source files
- Attached to Pawn via the Experience's `AddComponents` mechanism
- Tick-driven Pawn data is passed to MetaSound parameters
