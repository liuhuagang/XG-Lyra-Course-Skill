# Input Binding Settings

## Overview

Input bindings are divided into two parts: keyboard & mouse settings and gamepad settings. Keyboard & mouse settings are created by `InitializeMouseAndKeyboardSettings`, and gamepad settings by `InitializeGamepadSettings`.

## Keyboard & Mouse Settings

```
MouseAndKeyboardSettings (UGameSettingCollection)
  ├── DisplayName: "Keyboard & Mouse"
  │
  ├── Sensitivity (UGameSettingCollection)
  │     ├── MouseSensitivityX (UGameSettingValueScalarDynamic)
  │     │     └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetMouseSensitivityX)
  │     │     └── Range: 0~10, Step 0.01
  │     ├── MouseSensitivityY (UGameSettingValueScalarDynamic)
  │     │     └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetMouseSensitivityY)
  │     └── TargetingMultiplier (UGameSettingValueScalarDynamic)
  │           └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetTargetingMultiplier)
  │
  ├── Invert (UGameSettingCollection)
  │     └── InvertVerticalAxis (UGameSettingValueDiscreteDynamic_Bool)
  │           └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetInvertVerticalAxis)
  │
  └── Key Bindings (UGameSettingCollection)
        └── [ULyraSettingKeyboardInput × N dynamically generated by config]
              └── From UEnhancedPlayerMappableKeyProfile::PlayerMappedKeys
```

### Sensitivity Data

Mouse sensitivity is stored in `ULyraSettingsShared` (user-bound), bound via `GET_SHARED_SETTINGS_FUNCTION_PATH`.

### ULyraSettingBasedScalar

- **Header**: [LyraInputModifiers.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Input/LyraInputModifiers.h)
- **Inheritance**: `UObject` → `UInputModifier` → `ULyraSettingBasedScalar`
- Reads property values from `ULyraSettingsShared` via reflection (`FindPropertyByName`) as sensitivity scaling factors
- Used to apply game setting sensitivity values to the Enhanced Input processing pipeline

## Gamepad Settings

```
GamepadSettings (UGameSettingCollection)
  ├── DisplayName: "Gamepad"
  │
  └── GamepadSensitivity (UGameSettingValueDiscrete)
        └── Uses ULyraAimSensitivityData data asset
              └── Maps ELyraGamepadSensitivity → float
                    └── Slow / Slow2 / Normal / Fast2 / Fast / Insane...
              └── Read by ULyraInputModifierGamepadSensitivity
```

### ULyraAimSensitivityData

- **Header**: [LyraAimSensitivityData.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Input/LyraAimSensitivityData.h)
- **Inheritance**: `UObject` → `UPrimaryDataAsset` → `ULyraAimSensitivityData`
- Maps `ELyraGamepadSensitivity` enum values to `float` sensitivity values

### ULyraInputModifierGamepadSensitivity

- **Header**: [LyraInputModifiers.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Input/LyraInputModifiers.h)
- Reads `GetGamepadLookSensitivityPreset` and `GetGamepadTargetingSensitivityPreset` from `ULyraSettingsShared`
- Calculates the actual sensitivity value using the `ULyraAimSensitivityData` data asset

### ULyraInputModifierAimInversion

- Reads `GetInvertVerticalAxis`/`GetInvertHorizontalAxis` from `ULyraSettingsShared`
- Inverts input values based on inversion state

## Key Binding System

### Initialization Flow

```
InitializeMouseAndKeyboardSettings
  └── UserSettings = ULyraLocalPlayer->GetUserSettings<ULyraInputUserSettings>()
        └── KeyProfiles = UserSettings->GetAllAvailableKeyProfiles()
              └── For each Profile:
                    └── MappingRows = Profile->GetPlayerMappingRows()
                          └── For each MappingRow:
                                └── Create ULyraSettingKeyboardInput
                                      ├── ActionMappingName = Row.MappingName
                                      ├── QueryOptions = FPlayerMappableKeyQueryOptions
                                      ├── ProfileIdentifier = Profile->GetProfileIdentifer()
                                      └── Add to Key Bindings collection
```

### ULyraSettingKeyboardInput

- **Header**: [LyraSettingKeyboardInput.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Settings/CustomSettings/LyraSettingKeyboardInput.h)
- **Inheritance**: `UObject` → `UGameSetting` → `UGameSettingValue` → `ULyraSettingKeyboardInput`

Core methods:

| Method | Description |
|------|------|
| `InitializeInputData(Profile, MappingData, QueryOptions)` | Initialize key data |
| `ChangeBinding(Slot, NewKey)` | Change key binding |
| `GetAllMappedActionsFromKey(Key, QueryOptions)` | Get all actions bound to a key |
| `IsMappingCustomized()` | Check if key mapping has been customized |

### Key Registration Flow

```
UGameFeatureAction_AddInputContextMapping
  └── RegisterInputMappingContextsForLocalPlayer(LocalPlayer)
        └── Settings->RegisterInputMappingContext(IMC_InputConfiguration)
              └── Profile.PlayerMappedKeys.FindOrAdd(MappingName)
                    └── FPlayerMappedKey contains Slot and Key
```

### EPlayerMappableKeySlot

```
First / Second / Third / Fourth / Fifth / Sixth / Seventh / Unspecified / Max
```

The input settings interface uses `First` and `Second` key slots by default.
