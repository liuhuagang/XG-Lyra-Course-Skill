# Gameplay Settings

## Overview

Gameplay settings are created by the `InitializeGameplaySettings` function, located in `LyraGameSettingRegistry_Gameplay.cpp`. It includes language settings and replay recording settings.

## InitializeGameplaySettings Structure

```
GameplaySettings (UGameSettingCollection)
  ├── DisplayName: "Gameplay"
  │
  ├── Language (ULyraSettingValueDiscrete_Language)
  │     └── Header: LyraSettingValueDiscrete_Language.h
  │     └── Uses ULyraSettingsShared for language switching
  │
  └── Replays (UGameSettingCollection)
        ├── RecordReplay (UGameSettingValueDiscreteDynamic_Bool)
        │     └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetRecordReplay)
        │     └── Platform condition: ULyraReplaySubsystem::GetPlatformSupportTraitTag()
        └── KeepReplayLimit (UGameSettingValueDiscreteDynamic_Number)
              └── Range: 0~20
              └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetKeepReplayLimit)
              └── Platform condition: ULyraReplaySubsystem::GetPlatformSupportTraitTag()
```

## Language Settings

### ULyraSettingValueDiscrete_Language

- **Header**: [LyraSettingValueDiscrete_Language.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Settings/CustomSettings/LyraSettingValueDiscrete_Language.h)

Workflow:

```
GetDiscreteOptions()
  └── GetAllLocalizedCultures() — Get from FTextLocalizationManager
        └── Build option list:
              ├── System default language (first item)
              └── Each available Culture displayed as: "{NativeName} ({Name})"

Apply()
  └── ULyraSettingsShared::SetPendingCulture(Culture)
        └── Language change staged
  └── Show confirmation dialog:
        └── UCommonMessagingSubsystem::ShowConfirmation(OK/Cancel)
              ├── OK → Apply language
              └── Cancel → ULyraSettingsShared::ClearPendingCulture()

ResetToDefault()
  └── ULyraSettingsShared::ResetToDefaultCulture()
        └── Clear staged language

RestoreToInitial()
  └── ULyraSettingsShared::ClearPendingCulture()
```

### Language Change Confirmation

Language change is a destructive operation (requires a restart to fully take effect), so Lyra uses a confirmation dialog to prevent accidental changes. In `WITH_EDITOR` mode, an additional PIE warning is also shown.

## Replay Settings

### RecordReplay

- Boolean type setting, controls whether to auto-record replays
- Data stored in `ULyraSettingsShared`

### KeepReplayLimit

- Numeric type setting (0~20), controls the number of replay files to keep
- `0` means no limit

### Platform Condition

- Gets the platform trait tag via `ULyraReplaySubsystem::GetPlatformSupportTraitTag()`
- If the platform does not support replays, replay settings are hidden using `FWhenPlatformHasTrait::KillIfMissing`
