# Audio Settings

## Overview

Audio settings are created by the `InitializeAudioSettings` function, located in `LyraGameSettingRegistry_Audio.cpp`. Audio settings are divided into two main sections: Volume and Sound.

## InitializeAudioSettings Structure

```
AudioSettings (UGameSettingCollection)
  ├── DisplayName: "Audio"
  │
  ├── Volume (UGameSettingCollection)
  │     ├── OverallVolume (UGameSettingValueScalarDynamic)
  │     │     └── Data source: GET_LOCAL_SETTINGS_FUNCTION_PATH(GetOverallVolume)
  │     │     └── Format: ZeroToOnePercent (0~1 → 0%~100%)
  │     ├── MusicVolume (UGameSettingValueScalarDynamic)
  │     │     └── Data source: GET_LOCAL_SETTINGS_FUNCTION_PATH(GetMusicVolume)
  │     ├── SoundEffectsVolume (UGameSettingValueScalarDynamic)
  │     │     └── Data source: GET_LOCAL_SETTINGS_FUNCTION_PATH(GetSoundFXVolume)
  │     ├── DialogueVolume (UGameSettingValueScalarDynamic)
  │     │     └── Data source: GET_LOCAL_SETTINGS_FUNCTION_PATH(GetDialogueVolume)
  │     └── VoiceChatVolume (UGameSettingValueScalarDynamic)
  │           └── Data source: GET_LOCAL_SETTINGS_FUNCTION_PATH(GetVoiceChatVolume)
  │
  └── Sound (UGameSettingCollection)
        ├── SubtitlesPage (UGameSettingCollectionPage)
        │     ├── DisplayName: "Subtitles"
        │     ├── SubtitlesEnabled (UGameSettingValueDiscreteDynamic_Bool)
        │     │     └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetSubtitlesEnabled)
        │     ├── SubtitlesTextSize (UGameSettingValueDiscreteDynamic_Enum)
        │     │     └── Enum values: Small / Medium / Large / ExtraLarge
        │     │     └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetSubtitlesTextSize)
        │     ├── SubtitlesTextColor (UGameSettingValueDiscreteDynamic_Color)
        │     │     └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetSubtitlesTextColor)
        │     ├── SubtitlesTextBorder (UGameSettingValueDiscreteDynamic_Enum)
        │     │     └── Enum values: None / Outline / DropShadow
        │     │     └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetSubtitlesTextBorder)
        │     └── SubtitlesBackgroundOpacity (UGameSettingValueDiscreteDynamic_Enum)
        │           └── Enum values: 0%/25%/50%/75%/100%
        │           └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetSubtitlesBackgroundOpacity)
        ├── AudioOutputDevice (ULyraSettingValueDiscreteDynamic_AudioOutputDevice)
        │     └── Platform condition: TAG_Platform_Trait_SupportsChangingAudioOutputDevice
        │     └── Data source: GET_LOCAL_SETTINGS_FUNCTION_PATH(GetAudioOutputDeviceId)
        ├── BackgroundAudio (UGameSettingValueDiscreteDynamic_Enum)
        │     └── Platform condition: TAG_Platform_Trait_SupportsBackgroundAudio
        │     └── Data source: GET_SHARED_SETTINGS_FUNCTION_PATH(GetAllowAudioInBackgroundSetting)
        ├── HeadphoneMode (UGameSettingValueDiscreteDynamic_Enum)
        │     └── Data source: GET_LOCAL_SETTINGS_FUNCTION_PATH(GetHeadphoneMode)
        │     └── Custom condition: CanModifyHeadphoneModeEnabled() lambda
        └── HDRAudio (UGameSettingValueDiscreteDynamic_Bool)
              └── Data source: GET_LOCAL_SETTINGS_FUNCTION_PATH(GetHDRAudioModeEnabled)
```

## Data Source Pattern

All volume settings use `GET_LOCAL_SETTINGS_FUNCTION_PATH` to bind to `ULyraSettingsLocal` properties. Subtitle settings use `GET_SHARED_SETTINGS_FUNCTION_PATH` to bind to `ULyraSettingsShared` properties.

## Platform Trait Control

| Setting | Platform Tag | Behavior |
|------|---------|------|
| Audio Output Device | `TAG_Platform_Trait_SupportsChangingAudioOutputDevice` | Kill if missing |
| Background Audio | `TAG_Platform_Trait_SupportsBackgroundAudio` | Kill if missing |
| Headphone Mode | Custom lambda `CanModifyHeadphoneModeEnabled()` | Disable based on runtime condition |
