# Performance Stats Settings

## Overview

Performance stats settings are the most complex subsystem in the settings system, involving CPU/GPU performance data collection, network statistics (Ping/Packet Loss/Packet Rate), latency tracking (NVIDIA Reflex), and real-time rendering of Slate custom charts.

Performance stats settings are created by the `AddPerformanceStatPage` function, located in `LyraGameSettingRegistry_PerfStats.cpp`.

## AddPerformanceStatPage Structure

```
PerformanceStatsPage (UGameSettingCollectionPage)
  ├── DisplayName: "Performance Stats"
  │
  ├── Performance (UGameSettingCollection)
  │     └── [Settings generated per ELyraDisplayablePerformanceStat × N]
  │           ├── ClientFPS → ULyraSettingValueDiscrete_PerfStat
  │           ├── ServerFPS → ULyraSettingValueDiscrete_PerfStat
  │           ├── IdleTime → ULyraSettingValueDiscrete_PerfStat
  │           ├── FrameTime → ULyraSettingValueDiscrete_PerfStat
  │           ├── FrameTime_GameTime → ULyraSettingValueDiscrete_PerfStat
  │           ├── FrameTime_RenderTime → ULyraSettingValueDiscrete_PerfStat
  │           ├── FrameTime_RHIThread → ULyraSettingValueDiscrete_PerfStat
  │           └── FrameTime_GPUTime → ULyraSettingValueDiscrete_PerfStat
  │
  ├── Network (UGameSettingCollection)
  │     ├── Ping → ULyraSettingValueDiscrete_PerfStat
  │     ├── PacketLoss_Incoming → ULyraSettingValueDiscrete_PerfStat
  │     ├── PacketLoss_Outgoing → ULyraSettingValueDiscrete_PerfStat
  │     ├── PacketRate_Incoming → ULyraSettingValueDiscrete_PerfStat
  │     ├── PacketRate_Outgoing → ULyraSettingValueDiscrete_PerfStat
  │     ├── PacketSize_Incoming → ULyraSettingValueDiscrete_PerfStat
  │     └── PacketSize_Outgoing → ULyraSettingValueDiscrete_PerfStat
  │
  └── Latency (UGameSettingCollection)
        ├── Latency_Total → ULyraSettingValueDiscrete_PerfStat
        │     └── Edit condition: FGameSettingEditCondition_LatencyStatsSupported
        ├── Latency_Game → ULyraSettingValueDiscrete_PerfStat
        │     └── Edit condition: FGameSettingEditCondition_LatencyStatsCurrentlyEnabled
        └── Latency_Render → ULyraSettingValueDiscrete_PerfStat
              └── Edit condition: FGameSettingEditCondition_LatencyMarkersSupported
```

## ELyraDisplayablePerformanceStat

- **Header**: [LyraPerformanceStatTypes.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Performance/LyraPerformanceStatTypes.h)

```cpp
enum class ELyraDisplayablePerformanceStat : uint8
{
    ClientFPS,              // Client frame rate
    ServerFPS,              // Server frame rate
    IdleTime,               // Idle time
    FrameTime,              // Frame time (total)
    FrameTime_GameThread,   // Game thread frame time
    FrameTime_RenderThread, // Render thread frame time
    FrameTime_RHIThread,    // RHI thread frame time
    FrameTime_GPU,          // GPU frame time
    Ping,                   // Network latency
    PacketLoss_Incoming,    // Incoming packet loss
    PacketLoss_Outgoing,    // Outgoing packet loss
    PacketRate_Incoming,    // Incoming packet rate
    PacketRate_Outgoing,    // Outgoing packet rate
    PacketSize_Incoming,    // Incoming packet size
    PacketSize_Outgoing,    // Outgoing packet size
    Latency_Total,          // Total latency (end-to-end)
    Latency_Game,           // Game latency
    Latency_Render,         // Render latency

    Count                   // Static check = 18
};
static_assert(ELyraDisplayablePerformanceStat::Count == 18, "...");
```

```
ULyraPerformanceStatSubsystem
  ├── Tracker (FLyraPerformanceStatCache*)
  │     └── Performance data cache
  ├── StatDataTMap (TMap<ELyraDisplayablePerformanceStat, FSampledStatCache>)
```

## FLyraPerformanceStatCache

- **Inheritance**: `IPerformanceDataConsumer`
- Registered to the engine pipeline via `GEngine->AddPerformanceDataConsumer(Tracker)`

### ProcessFrame Data Processing

```
IPerformanceDataConsumer::FFrameData
  ├── DeltaSeconds
  ├── TrueDeltaSeconds
  ├── IdleSeconds
  ├── GameThreadTimeSeconds
  ├── RenderThreadTimeSeconds
  ├── RHIThreadTimeSeconds
  ├── GPUTimeSeconds
  └── ...

FLyraPerformanceStatCache::ProcessFrame(FrameData)
  ├── Calculate ClientFPS = 1.0 / FrameData.TrueDeltaSeconds
  ├── Calculate ServerFPS (from UWorld::GetServerWorldTimeSecondsDelta)
  ├── Record IdleTime = FrameData.IdleSeconds
  ├── Record FrameTime = FrameData.TrueDeltaSeconds
  ├── Record GameThread/RenderThread/RHIThread/GPU frame times
  ├── Ping (from PlayerState)
  ├── PacketLoss/Rate/Size (from UNetConnection)
  └── Latency (from ILatencyMarkerModule)
```

## FSampledStatCache

- Ring buffer implementation, default capacity of 125 sample points
- Automatically overwrites oldest data

| Method | Description |
|------|------|
| `GetLastCachedStat()` | Get the last cached value |
| `GetAverage()` | Get the average value |
| `GetMin()` | Get the minimum value |
| `GetMax()` | Get the maximum value |
| `ForEachCurrentSample(Func)` | Iterate over all current samples |

## Slate Chart Rendering

### SLyraLatencyGraph

- **Inheritance**: `SLeafWidget`
- Custom `OnPaint` implementation

```
OnPaint(Args, OutDrawElements, Layer, ...)
  ├── Draw background
  ├── Draw grid lines
  ├── Draw target line (green threshold line)
  ├── For each Stat:
  │     ├── Collect sample points → FVector2D[] 
  │     └── FSlateDrawElement::MakeLines(OutDrawElements, Layer, PaintGeometry, Points)
  └── Draw legend
```

### Widget Hierarchy

```
ULyraPerfStatContainerBase (UCommonUserWidget)
  └── [ULyraPerfStatWidgetBase × N]
        ├── Text mode: Directly display value
        └── Graph mode: Embeds SLyraLatencyGraph or ULyraPerfStatGraph
```

## Edit Conditions

### FGameSettingEditCondition_LatencyStatsSupported

- Checks if the platform supports latency statistics
- Calls `ULyraSettingsLocal::DoesPlatformSupportLatencyTrackingStats()`

### FGameSettingEditCondition_LatencyStatsCurrentlyEnabled

- Checks if latency statistics are currently enabled
- Binds to `OnLatencyStatIndicatorSettingsChangedEvent`
- Listens for latency marker setting changes

### FGameSettingEditCondition_LatencyMarkersSupported

- Checks if the platform supports latency markers (NVIDIA Reflex)
- Calls `ULyraSettingsLocal::DoesPlatformSupportLatencyMarkers()`
