## Architecture Layers

```
Item Definition Layer
  ULyraInventoryItemDefinition — Item template (UObject, Blueprintable, Abstract)
    └── Fragments[] — Item fragment array (EditInlineNew)
          ULyraInventoryItemFragment — Fragment base class
            ├── Custom subclasses (define item behavior/attributes)

Item Instance Layer
  ULyraInventoryItemInstance — Runtime item instance
    ├── ItemDef — Points to definition
    └── StatTags — Stat tag stack (Replicated)

Inventory List Layer
  FLyraInventoryList — FFastArraySerializer
    └── Entries[] — FLyraInventoryEntry
          ├── Instance -> ULyraInventoryItemInstance
          └── StackCount — Stack count

Inventory Manager Layer
  ULyraInventoryManagerComponent — UActorComponent
    └── InventoryList — Item list
```

## ULyraInventoryItemDefinition

[ULyraInventoryItemDefinition](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Inventory/LyraInventoryItemDefinition.h) is an abstract Blueprintable UObject serving as an item template.

| Member | Type | Description |
|------|------|------|
| `DisplayName` | FText | Item display name |
| `Fragments` | TArray\<TObjectPtr\<ULyraInventoryItemFragment\>\> | Item fragments (Instanced) |

**Core Methods:**
- `FindFragmentByClass(TSubclassOf<ULyraInventoryItemFragment>)` — Finds fragment by class

## ULyraInventoryItemFragment

[ULyraInventoryItemFragment](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Inventory/LyraInventoryItemDefinition.h) is an `EditInlineNew` abstract base class defining specific item behavior.

| Method | Description |
|------|------|
| `OnInstanceCreated(ULyraInventoryItemInstance*)` | Callback when instance is created |

Add fragment subclasses in the item definition BP to extend item functionality (e.g., weapon fragment, consumable fragment, etc.).

## ULyraInventoryItemInstance

[ULyraInventoryItemInstance](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Inventory/LyraInventoryItemInstance.h) is a runtime item instance (Replicated).

| Member | Type | Description |
|------|------|------|
| `StatTags` | FGameplayTagStackContainer | Stat tag stack (Replicated) |
| `ItemDef` | TSubclassOf\<ULyraInventoryItemDefinition\> | Item definition (Replicated) |

**Core Methods:**
- `AddStatTagStack(Tag, Count)` — Increases stat tag count
- `RemoveStatTagStack(Tag, Count)` — Decreases stat tag count
- `GetStatTagStackCount(Tag)` — Gets stat tag count
- `HasStatTag(Tag)` — Checks if a stat tag exists
- `GetItemDef()` — Gets item definition
- `FindFragmentByClass(Class)` — Finds fragment by class (delegates to ItemDef)

## FLyraInventoryList & FLyraInventoryEntry

[FLyraInventoryList](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Inventory/LyraInventoryManagerComponent.h) inherits `FFastArraySerializer`, implementing network delta replication.

**FLyraInventoryEntry:**
| Member | Type | Description |
|------|------|------|
| `Instance` | TObjectPtr\<ULyraInventoryItemInstance\> | Item instance |
| `StackCount` | int32 | Stack count |
| `LastObservedCount` | int32 (NotReplicated) | Client's last observed count |

**FLyraInventoryList Methods:**
- `GetAllItems()` — Gets all items
- `AddEntry(ItemClass, StackCount)` — Adds by class
- `AddEntry(Instance)` — Adds by instance
- `RemoveEntry(Instance)` — Removes item
- `NetDeltaSerialize` — Network delta serialization

## ULyraInventoryManagerComponent

[ULyraInventoryManagerComponent](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Inventory/LyraInventoryManagerComponent.h) is the main API entry point.

**Core Methods:**

| Method | Description |
|------|------|
| `CanAddItemDefinition(ItemDef, StackCount)` | Checks if item can be added |
| `AddItemDefinition(ItemDef, StackCount)` | Adds item by definition, returns instance |
| `AddItemInstance(Instance)` | Adds instance directly |
| `RemoveItemInstance(Instance)` | Removes instance |
| `GetAllItems()` | Gets all instance list |
| `FindFirstItemStackByDefinition(ItemDef)` | Finds first stack by definition |
| `GetTotalItemCountByDefinition(ItemDef)` | Gets total count of specified item |
| `ConsumeItemsByDefinition(ItemDef, NumToConsume)` | Consumes specified number of items |

**FLyraInventoryChangeMessage:**
| Field | Type | Description |
|------|------|------|
| `InventoryOwner` | Owner component |
| `Instance` | Item instance |
| `NewCount` | New count |
| `Delta` | Delta count |

## IPickupable Interface

[IPickupable](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Inventory/IPickupable.h) interface defines the spec for pickupable items.

**FPickupTemplate:**
| Member | Description |
|------|------|
| `StackCount` | Stack count |
| `ItemDef` | Item definition class |

**FPickupInstance:**
| Member | Description |
|------|------|
| `Item` | Item instance reference |

**FInventoryPickup:**
| Member | Description |
|------|------|
| `Instances` | Instance array |
| `Templates` | Template array |

**Core Methods:**
- `GetPickupInventory()` — Pure virtual, returns FInventoryPickup

**UPickupableStatics Blueprint Function Library:**
- `GetFirstPickupableFromActor(Actor)` — Gets IPickupable from Actor
- `AddPickupToInventory(InventoryComponent, Pickup)` — Adds pickup to inventory (server only)
