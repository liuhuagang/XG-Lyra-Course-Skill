## IInteractableTarget

[IInteractableTarget](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Interaction/IInteractableTarget.h) defines the core interface for interactable objects.

```cpp
UINTERFACE()
class UInteractableTarget : public UInterface { };

class IInteractableTarget
{
    // Collect interaction options, implemented by interaction target
    virtual void GatherInteractionOptions(
        const FInteractionQuery& InteractQuery,
        FInteractionOptionBuilder& OptionBuilder) = 0;

    // Customize interaction event data, optional override
    virtual void CustomizeInteractionEventData(
        const FGameplayTag& InteractionEventTag,
        FGameplayEventData& InOutEventData) { }
};
```

## FInteractionOption

[FInteractionOption](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Interaction/InteractionOption.h) describes an interaction option:

| Field | Type | Description |
|------|------|------|
| `InteractableTarget` | TScriptInterface\<IInteractableTarget\> | Interaction target reference |
| `Text` | FText | Interaction display text |
| `SubText` | FText | Interaction sub-text |
| `InteractionAbilityToGrant` | TSubclassOf\<UGameplayAbility\> | Interaction GA granted to initiator |
| `TargetAbilitySystem` | TObjectPtr\<UAbilitySystemComponent\> | Target ASC |
| `TargetInteractionAbilityHandle` | FGameplayAbilitySpecHandle | Interaction Ability on target |
| `InteractionWidgetClass` | TSoftClassPtr\<UUserWidget\> | Interaction UI Widget |

Two interaction methods:
1. **Grant GA to initiator**: Grants an interaction GA via `InteractionAbilityToGrant`; the GA executes the interaction logic
2. **Trigger target-side Ability**: Triggers the interaction Ability on the target via `TargetAbilitySystem` + `TargetInteractionAbilityHandle`

## FInteractionOptionBuilder

Non-UObject helper builder class:

```cpp
class FInteractionOptionBuilder
{
    TScriptInterface<IInteractableTarget> Scope;

    void AddInteractionOption(const FInteractionOption& Option)
    {
        // Automatically assigns Scope to Option.InteractableTarget
        Option.InteractableTarget = Scope;
    }
};
```

## ALyraWorldCollectable

[ALyraWorldCollectable](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Plugins/GameFeatures/ShooterCore/Source/ShooterCoreRuntime/Public/LyraWorldCollectable.h) implements both `IInteractableTarget` and `IPickupable`, serving as a world interaction pickup.

**Inheritance Chain:** `AActor` + `IInteractableTarget` + `IPickupable`

| Member | Type | Description |
|------|------|------|
| `Option` | FInteractionOption | Interaction option configuration |
| `StaticInventory` | FInventoryPickup | Static pickup inventory |

**Core Methods:**
- `GatherInteractionOptions(InteractQuery, InteractionBuilder)` — Adds itself as an interaction option
- `GetPickupInventory()` — Returns pickup inventory

### Interaction Pickup Complete Flow

```
1. Player approaches ALyraWorldCollectable
2. Detect and gather interaction options
     ├── Use Overlap/Hit detection to find interactable Actors
     ├── Call GetInteractableTargetsFromActor()
     │     └── Get all IInteractableTarget interfaces
     ├── Call GatherInteractionOptions()
     │     └── Populate FInteractionOption list
     └── IInteractionInstigator::ChooseBestInteractionOption()
           └── Select best interaction option

3. Execute interaction
     ├── Grant interaction GA (InteractionAbilityToGrant)
     └── Interaction GA activates
           ├── Call UPickupableStatics::AddPickupToInventory()
           │     └── Write FInventoryPickup into inventory
           │           └── ULyraInventoryManagerComponent::AddItemDefinition/AddItemInstance()
           └── Play pickup effects/sounds
                 └── Remove world pickup
```
