## ULyraHealthComponent

[ULyraHealthComponent](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Character/LyraHealthComponent.h) is a UActorComponent that serves as the GameObject-side bridge for the attribute set (ULyraHealthSet), converting attribute changes into game events.

## Responsibility Boundaries

| Responsibility | Owner |
|------|------|
| Attribute storage and network sync | ULyraHealthSet (data layer) |
| Attribute change event translation | ULyraHealthComponent (logic layer) |
| Death state machine management | ULyraHealthComponent |
| GameplayTag cleanup | ULyraHealthComponent |

## Death State Machine

`ELyraDeathState` enum:

```
NotDead → DeathStarted → DeathFinished
```

| State | Description |
|------|------|
| `NotDead` | Alive |
| `DeathStarted` | Death started (playing death animation/ragdoll, etc.) |
| `DeathFinished` | Death finished (cannot be revived) |

**Transition Methods:**

```cpp
void StartDeath();   // NotDead → DeathStarted
void FinishDeath();  // DeathStarted → DeathFinished
```

**State Queries:**

- `GetDeathState()` — Gets current state
- `IsDeadOrDying()` — Whether dead or dying (`DeathState != NotDead`)

## Attribute Event Delegates

| Delegate | Parameters | Trigger Moment |
|------|------|----------|
| `OnHealthChanged` | OldValue, NewValue, Instigator | When Health attribute changes |
| `OnMaxHealthChanged` | OldValue, NewValue, Instigator | When MaxHealth attribute changes |
| `OnDeathStarted` | OwningActor | When death starts |
| `OnDeathFinished` | OwningActor | When death finishes |

## Handle Methods

When HealthSet's delegates trigger, HealthComponent's Handle methods are called:

```cpp
void ULyraHealthComponent::HandleHealthChanged(AActor* Instigator, float OldValue, float NewValue)
{
    // Broadcast OnHealthChanged delegate
    OnHealthChanged.Broadcast(this, OldValue, NewValue, Instigator);
}

void ULyraHealthComponent::HandleMaxHealthChanged(AActor* Instigator, float OldValue, float NewValue)
{
    OnMaxHealthChanged.Broadcast(this, OldValue, NewValue, Instigator);
}

void ULyraHealthComponent::HandleOutOfHealth(AActor* DamageInstigator, AActor* DamageCauser, ...)
{
    // Start death sequence
    StartDeath();
}
```

```cpp
void ULyraHealthComponent::OnRep_DeathState(ELyraDeathState OldDeathState)
{
    // Execute corresponding client logic based on old/new state transition

```

## Self-Destruct

```cpp
void DamageSelfDestruct(bool bFellOutOfWorld);
```

When `bFellOutOfWorld` is true, applies damage with the `TAG_Gameplay_FellOutOfWorld` tag; otherwise applies `TAG_Gameplay_DamageSelfDestruct` tag.

## GameplayTag Cleanup

```cpp
void ClearGameplayTags();
```

Called during the death flow to remove specific GameplayTags from the character, ensuring correct state after death.

## Call Architecture

```
ULyraHealthSet::PostGameplayEffectExecute()
  └── OnHealthChanged.Broadcast(...)
        └── ULyraHealthComponent::HandleHealthChanged(...)
              └── OnHealthChanged.Broadcast(...)  // External delegate

ULyraHealthSet::PostGameplayEffectExecute()
  └── OnOutOfHealth.Broadcast(...)
        └── ULyraHealthComponent::HandleOutOfHealth(...)
              └── StartDeath()
                    └── OnDeathStarted.Broadcast(...)
```
