# Weapon Fire Ability & Prediction System

## Overview

`ULyraGameplayAbility_RangedWeapon` is the fire GameplayAbility for ranged weapons, handling the complete shooting flow: aiming trace, bullet spread, hit detection, damage application, and providing client-side instant feedback through UE's GameplayAbility prediction system.

### Constructor

- Adds `TAG_WeaponFireBlocked` to `SourceBlockedTags`, preventing fire when owning this Tag

### Activation Check (CanActivateAbility)

- Condition: `GetWeaponInstance() != nullptr`
- I.e., a ranged weapon instance must be equipped

## Fire Flow

### ActivateAbility

1. Binds target data callback: `AbilityTargetDataSetDelegate(CurrentSpecHandle, ActivationPredictionKey).AddUObject(this, &OnTargetDataReadyCallback)`
2. Calls `UpdateFiringTime()` — Updates weapon's TimeLastFired
3. Calls parent `ActivateAbility`

> The callback binding's significance: When the client predicts activation, the server calls this delegate after replicating TargetData. The client also calls the callback directly after locally generating TargetData.

### StartRangedWeaponTargeting

Entry point for triggering fire tracing:

1. Creates `FScopedPredictionWindow` — Opens a prediction window
2. Calls `PerformLocalTargeting(OutHits)` — Executes local bullet tracing
3. Constructs `FGameplayAbilityTargetDataHandle`:
   - Each hit result creates `FLyraGameplayAbilityTargetData_SingleTargetHit`
   - Contains `CartridgeID` (uniquely identifies this ammunition)
4. If locally controlled client: `WeaponStateComponent->AddUnconfirmedServerSideHitMarkers(TargetData, FoundHits)` — Records unconfirmed hit markers
5. Calls `OnTargetDataReadyCallback(TargetData, FGameplayTag())`

### PerformLocalTargeting

1. Gets aiming direction: via `GetTargetingTransform()` to get Camera-toward-Focus transform
2. Computes `StartTrace` and `EndAim` (MaxDamageRange distance)
3. Calls `TraceBulletsInCartridge(FRangedWeaponFiringInput, OutHits)`

### TraceBulletsInCartridge

**Parameters:**
- `FRangedWeaponFiringInput` — Contains StartTrace, EndAim, AimDir, WeaponData

**Flow:**

For each bullet (BulletsPerCartridge):
1. Compute spread direction: `VRandConeNormalDistribution(AimDir, SpreadAngleRad, SpreadExponent)`
2. Compute actual end point: `EndTrace = StartTrace + SpreadDir * MaxDamageRange`
3. Call `DoSingleBulletTrace(StartTrace, EndTrace, SweepRadius, bIsSimulated, OutHits)`

### DoSingleBulletTrace

**Two-Phase Trace Strategy:**

1. **Phase 1 — Ray Trace**:
   - Uses `WeaponTrace()`
   - Calls `FindFirstPawnHitResult(Hits)` to check if a Pawn was hit
2. **Phase 2 — Sweep Trace** (only if ray missed Pawn and SweepRadius > 0):
   - Uses `SweepRadius` for sweep trace
   - If sweep hits a Pawn, use sweep result; otherwise keep ray result

### FindFirstPawnHitResult

Searches the HitResults array for the first hit Pawn (not self, not ignored actor).

### WeaponTrace

- Uses `GetWorld()->LineTraceMultiByChannel` or `SweepMultiByChannel`
- Trace channel determined via `DetermineTraceChannel()`
- Ignored actors added via `AddAdditionalTraceIgnoreActors(TraceParams)`

### OnTargetDataReadyCallback

Processing after receiving target data:

1. **Server** (`HasAuthority(&ActivationInfo)`):
   - Creates `FScopedPredictionWindow` (server prediction window)
2. **Client→Server Sync** (locally controlled && not authoritative):
   - Calls `CallServerSetReplicatedTargetData()` — RPC sends TargetData to server
3. **Server Confirms Hits**:
   - Confirms hit markers via `WeaponStateComponent->ClientConfirmTargetData(UniqueId, bSuccess, HitReplaces)`
4. **CommitAbility** — Consumes costs (e.g., ammo)
5. **AddSpread** — Increases weapon spread
6. **Triggers Blueprint Event**: `OnRangedWeaponTargetDataReady(TargetData)` — BlueprintImplementableEvent
   - In Blueprint: iterate TargetData, apply damage GE to each hit target
7. **Cleanup**: `ConsumeClientReplicatedTargetData()`

## Damage Application & GEEC

- The fire ability itself does not directly compute damage; instead, it applies a damage GE to hit targets via `ApplyGameplayEffectToTarget`
- Damage calculation is performed by `ULyraDamageExecution` (GEEC):
  - **BaseDamage**: From `ULyraCombatSet`'s BaseDamage attribute
  - **DistanceAttenuation**: From `ILyraAbilitySourceInterface` (RangedWeaponInstance)
  - **PhysicalMaterialAttenuation**: From `ILyraAbilitySourceInterface` (RangedWeaponInstance)

## Cost System (ULyraAbilityCost_ItemTagStack)

- **CheckCost**: Checks if InventoryItemInstance has sufficient TagStack
- **ApplyCost**: Consumes the corresponding TagStack
- `bOnlyApplyCostOnHit`: Combined with `DetermineIfAbilityHitTarget` lambda, only consumes cost on hit

## Failure Notification

When Ability activation fails, notified via `NotifyAbilityFailed`:
- `ClientNotifyAbilityFailed` RPC → `HandleAbilityFailed`
- Broadcasts `TAG_ABILITY_SIMPLE_FAILURE_MESSAGE` (HUD simple failure prompt)
- Broadcasts `TAG_ABILITY_PLAY_MONTAGE_FAILURE_MESSAGE` (Montage failure prompt)

## Aiming Source Type (ELyraAbilityTargetingSource)

```cpp
enum class ELyraAbilityTargetingSource : uint8
{
    CameraTowardsFocus,    // From camera towards focus
    PawnForward,           // From Pawn center along Pawn direction
    PawnTowardsFocus,      // From Pawn center towards focus
    WeaponForward,         // From weapon muzzle along Pawn direction
    WeaponTowardsFocus,    // From weapon muzzle towards focus
    Custom                 // Blueprint custom
};
```

## GE Application Notes

When GE is applied via `FGameplayAbilityTargetData::ApplyGameplayEffectSpec`, a copy of `EffectContext` is created for each target (`EffectContext.Duplicate()`), preventing damage accumulation issues.
