# Damage Number Pop System (NumberPop)

## Overview

The NumberPop system displays damage numbers in screen-space or world-space upon hitting a target, providing visual damage feedback. Supports both Niagara text and mesh text rendering.

## Class Hierarchy

```
LyraDamagePopStyle (UDataAsset)
  └─ LyraDamagePopStyleNiagara (UDataAsset)
       └─ Damage number style using Niagara particle system

LyraNumberPopComponent (UActorComponent) [Abstract]
  ├─ LyraNumberPopComponent_NiagaraText
  └─ LyraNumberPopComponent_MeshText
```

## Damage Number Styles

### LyraDamagePopStyle

UDataAsset, base class defining damage number pop style.

### LyraDamagePopStyleNiagara

UDataAsset, damage number style using Niagara particle system:
- Defines Niagara system template
- Number rendering parameters (color, size, font)
- Animation parameters (float, fade out, etc.)

## Number Pop Components

### LyraNumberPopComponent

Abstract base class defining the number pop display interface.

### LyraNumberPopComponent_NiagaraText

Renders damage numbers using Niagara particle system:
- Based on Niagara text rendering
- Supports number animation (rising, fading out)
- Customizable colors and styles

### LyraNumberPopComponent_MeshText

Renders damage numbers in world-space using static mesh (3D Text):
- Suitable for world-space positioned damage numbers
- Supports rotation toward camera

## Trigger Flow

1. After damage GE is applied, triggered via GameplayCue
2. GameplayCue looks up NumberPopComponent on the Actor
3. Calls NumberPopComponent's display interface
4. Selects the appropriate DamagePopStyle based on damage type
5. Pops damage number at hit location
