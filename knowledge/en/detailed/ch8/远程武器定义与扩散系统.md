# Ranged Weapon Definition & Spread System

## Overview

The ranged weapon system extends the equipment system, defining runtime data for shooting weapons, including the Spread/Heat system, multi-state precision multipliers, distance damage falloff, and material damage multipliers.

### Spread/Heat System

Core concept: **Heat** serves as an intermediate value, mapped to **SpreadAngle** via a curve.

```
Per bullet: AddSpread() → Heat↑ → HeatToSpreadCurve → SpreadAngle↑
Over time:  Tick() → UpdateSpread() → Heat↓ (cooldown) → SpreadAngle↓
```

#### Curve Definitions

| Curve | X Axis | Y Axis | Purpose |
|------|------|------|------|
| HeatToSpreadCurve | Heat range | Spread angle | Heat → Spread angle |
| HeatToHeatPerShotCurve | Current Heat | Heat increment per shot | Heat added per shot |
| HeatToCoolDownPerSecondCurve | Current Heat | Cooldown rate/sec | Heat dissipated per second |

#### Precision Multiplier System

Four state multipliers, each interpolating independently, combined into a final composite multiplier:

| Multiplier | Detection Method | Transition Rate |
|------|----------|----------|
| StandingStillMultiplier | Speed ≤ StandingStillSpeedThreshold (80cm/s) | TransitionRate_StandingStill |
| CrouchingMultiplier | bIsCrouched | TransitionRate_Crouching |
| JumpFallMultiplier | IsFalling | TransitionRate_JumpingOrFalling |
| AimingMultiplier | CameraComponent->GetBlendInfo() checks TAG_Lyra_Weapon_SteadyAimingCamera | Direct |

**Combination:** `CombinedMultiplier = AimingMultiplier * StandingStillMultiplier * CrouchingMultiplier * JumpFallMultiplier`

#### First Shot Accuracy

Condition: `bAllowFirstShotAccuracy && bMinMultipliers && bMinSpread`
- `bMinMultipliers` — All multipliers have transitioned to their minimum values
- `bMinSpread` — Heat has cooled to minimum
- When active, `GetCalculatedSpreadAngleMultiplier()` returns 0.0, i.e., absolute precision

### Tick() Update Logic

```
Tick(DeltaSeconds):
    UpdateSpread(DeltaSeconds)       → Returns bMinSpread
    UpdateMultipliers(DeltaSeconds)  → Returns bMinMultipliers
    bHasFirstShotAccuracy = bAllowFirstShotAccuracy && bMinMultipliers && bMinSpread
```

### UpdateSpread() Flow

1. Compute `TimeSinceFired = CurrentTime - LastFireTime`
2. If `TimeSinceFired > SpreadRecoveryCooldownDelay`:
   - Get cooldown rate from `HeatToCoolDownPerSecondCurve`
   - `CurrentHeat = ClampHeat(CurrentHeat - CooldownRate * DeltaSeconds)`
3. `CurrentSpreadAngle = HeatToSpreadCurve.Eval(CurrentHeat)`
4. Returns whether `CurrentSpreadAngle` equals the minimum spread angle

### AddSpread() Flow (Triggered per Bullet)

1. Get heat increment from `HeatToHeatPerShotCurve.Eval(CurrentHeat)`
2. `CurrentHeat = ClampHeat(CurrentHeat + HeatPerShot)`
3. `CurrentSpreadAngle = HeatToSpreadCurve.Eval(CurrentHeat)`

### UpdateMultipliers() Flow

1. **StandingStillMultiplier**: Computes `MovementTargetValue` (MappedRangeClamped speed range), transitions via `FInterpTo`
2. **CrouchingMultiplier**: Transitions between 1.0 and configured value via `FInterpTo` based on `bIsCrouched`
3. **JumpFallMultiplier**: Transitions between 1.0 and configured value via `FInterpTo` based on `IsFalling`
4. **AimingAlpha**: Checks whether `TAG_Lyra_Weapon_SteadyAimingCamera` is blended via `GetPawn()->GetComponentByClass<ULyraCameraComponent>()->GetBlendInfo()`
5. **Combined = AimingMultiplier × StandingStillMultiplier × CrouchingMultiplier × JumpFallMultiplier**

### Other Configurations

- `BulletsPerCartridge` — Bullets per shot (shotgun > 1)
- `MaxDamageRange` — Max damage distance (default 25000cm)
- `BulletTraceSweepRadius` — Bullet trace sweep radius (0.0 means line trace)
- `SpreadExponent` — Spread exponent (>1 clusters bullet holes toward center)

### OnEquipped() Initialization

- `CurrentHeat` set to midpoint of heat range
- `StandingStillMultiplier`, `JumpFallMultiplier`, `CrouchingMultiplier` all initialized to 1.0
- Calls parent OnEquipped
