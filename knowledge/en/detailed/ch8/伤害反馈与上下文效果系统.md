# Damage Feedback & Context Effects System

## Overview

The damage feedback system (Context Effects) provides the ability to dynamically select and play sounds, visual effects, and Niagara effects based on physical material, surface type, and game context.

## Architecture

```
LyraContextEffectComponent (AActor Component)
  └─ Attached to interactive Actors, provides context effect queries

LyraContextEffectsSubsystem (UWorldSubsystem)
  └─ Global context effects manager, loads and manages effect libraries

LyraContextEffectsLibrary (UObject)
  └─ Effect asset library, organized by tags

LyraContextEffectsInterface (UInterface)
  └─ Interface implementable by Actors, provides custom context effects

AnimNotify_LyraContextEffects (UAnimNotify)
  └─ Triggers context effects in animation notifies
```

## Core Classes

### LyraContextEffectComponent

Attached to damageable Actors, provides functions to query which context effects the current Actor should use. Selects appropriate effects based on the Actor's physical material, gameplay tags, and other context information.

### LyraContextEffectsSubsystem

UWorld subsystem that manages all registered ContextEffectsLibraries:
- Loads and unloads effect libraries
- Queries appropriate effects based on context tags
- Manages and caches effect resources

### LyraContextEffectsLibrary

Data collection containing effect entries organized by GameplayTag:
- Each entry contains the effect type (sound/VFX/particles) and corresponding asset reference
- Supports matching queries by tag combinations

### LyraContextEffectsInterface

Interface implementable by Actors, allowing custom Actors to provide their own context effect logic instead of using the default physical material query.

### AnimNotify_LyraContextEffects

Notification frame placed in animation sequences (e.g., muzzle flash frame), on trigger:
1. Collects current context (physical material, gameplay tags, etc.)
2. Queries ContextEffectsSubsystem for appropriate effects
3. Spawns effects at the specified location

## Sound Feedback System

Physical material-based weapon sound system, including:
- **Fire Sounds**: Multiple variants, categorized by weapon type
- **Dry Click Sounds**: Empty magazine click sounds
- **Auto Load Sounds**: Automatic loading mechanical sounds
- **Magazine Sounds (ClipIn/ClipOut)**: Magazine change sounds
- **Environmental Distance Layers**: Close / Distant / Far
- **Interior/Exterior Differentiation**: Interior / Exterior

## Camera Shakes

Camera shakes triggered on weapon fire:
- CS_Weapon_Fire (Generic)
- CS_Weapon_Fire_Pistol (Pistol)
- CS_Weapon_Fire_Rifle (Rifle)
- CS_Weapon_Fire_Shotgun (Shotgun)

## Haptic Feedback (Force Feedback)

Gamepad force feedback effects:
- FFE_Weapon_Fire (Generic fire feedback)
- FFE_Weapon_Fire_Auto (Automatic weapon fire feedback)
- C_Weapon_AutoVibration series (amplitude/frequency/position parameter curves)
