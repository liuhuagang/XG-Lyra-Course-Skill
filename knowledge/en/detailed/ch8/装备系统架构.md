# Equipment System Architecture

## Overview

The Equipment system is the core framework in Lyra for attaching items/weapons to a Pawn. It uses a three-tier design: **Definition → Instance → ManagerComponent**, combined with **QuickBar** for player weapon switching.

## Core Class Hierarchy

```
ULyraEquipmentDefinition (UObject, Const, Abstract)
  └─ Defines "how to equip" — instance type, AbilitySet to grant, Actor to spawn

ULyraEquipmentInstance (UObject, BlueprintType, network-replicated)
  └─ Runtime equipment instance, holds Instigator and SpawnedActors

ULyraEquipmentManagerComponent (UPawnComponent)
  └─ Pawn-level equipment manager, maintains FLyraEquipmentList

ULyraQuickBarComponent (UControllerComponent)
  └─ Quick bar system, manages Inventory → Equipment equipping flow
```

## Equipment Instance (ULyraEquipmentInstance)

[LyraEquipmentInstance.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Equipment/LyraEquipmentInstance.h)

```cpp
UCLASS(BlueprintType, Blueprintable)
class ULyraEquipmentInstance : public UObject
{
    UObject* Instigator;              // Replicated—typically an InventoryItemInstance
    TArray<AActor*> SpawnedActors;    // Replicated—spawned Actors

    void SpawnEquipmentActors(const TArray<FLyraEquipmentActorToSpawn>& ActorsToSpawn);
    void DestroyEquipmentActors();

    virtual void OnEquipped();        // Calls K2_OnEquipped BP event
    virtual void OnUnequipped();      // Calls K2_OnUnequipped BP event
};
```

- `GetPawn()` is obtained via `Instigator` → `GetTypedOuter<APawn>()`
- `IsSupportedForNetworking()` returns true, supports network replication
- `OnEquipped()` calls SpawnEquipmentActors first, then triggers K2 event
- `OnUnequipped()` calls DestroyEquipmentActors first, then triggers K2 event

### FLyraEquipmentList (FastArraySerializer)

Implements network replication via the `FFastArraySerializer` mechanism, contains `TArray<FLyraAppliedEquipmentEntry> Entries`.

```cpp
struct FLyraAppliedEquipmentEntry : public FFastArraySerializerItem
{
    TSubclassOf<ULyraEquipmentDefinition> EquipmentDefinition;
    ULyraEquipmentInstance* Instance;
    FLyraAbilitySet_GrantedHandles GrantedHandles;  // Authority-only, not replicated
};
```

**`AddEntry()` Flow:**
1. Spawns `InstanceType` defined in the passed EquipmentDefinition
2. Calls `OnEquipped()` → internally calls SpawnEquipmentActors + K2_OnEquipped
3. Iterates `AbilitySetsToGrant`, calls `GiveToAbilitySystem(ASC, &GrantedHandles, Result)`

  > Here, `Result` is the newly created EquipmentInstance, passed as `SourceObject` to the AbilitySet grant flow, allowing Abilities to trace back to the EquipmentInstance via `GetSourceObject()`

4. Adds Entry to `Entries` array

**`RemoveEntry()` Flow:**
1. Calls `Instance->OnUnequipped()` → DestroyEquipmentActors + K2_OnUnequipped
2. `TakeFromAbilitySystem(GrantedHandles)` revokes all granted Abilities
3. Removes from Entries

## QuickBar (ULyraQuickBarComponent)

[View source](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Equipment/)

Component attached to the Controller, manages the Inventory → Equipment equipping trigger.

### Core Data

- `Slots: TArray<TObjectPtr<ULyraInventoryItemInstance>>` — Replicated, quick bar slots
- `ActiveSlotIndex: int32` — Replicated, currently active slot index

### Core Flow

**Adding Item to Slot** `AddItemToSlot(ULyraInventoryItemInstance* ItemInstance)`:
- Calls `GetNextFreeItemSlot()` to find an empty slot
- Places ItemInstance into that slot

**Activating Slot** `SetActiveSlotIndex(int32 NewIndex)` (Server Only):
1. If current slot has equipment → `UnequipItemInSlot()`
2. Sets `ActiveSlotIndex = NewIndex`
3. If new slot has an item → `EquipItemInSlot()`

**Equipping Slot** `EquipItemInSlot(int32 SlotIndex)`:
1. Gets `ULyraInventoryItemInstance` from `Slots[SlotIndex]`
2. Finds the `ULyraInventoryItemFragment_EquippableItem` Fragment on that item
3. Gets `EquipmentDefinition` from the Fragment
4. Gets `EquipmentManagerComponent`
5. Calls `EquipmentManager->EquipItem(EquipmentDefinition)` → returns `ULyraEquipmentInstance`
6. Calls `EquippedItem->SetInstigator(SlotItem)` — sets InventoryItemInstance as Instigator

  > Key design: Instigator points to InventoryItemInstance, allowing Equipment to trace back to the item in Inventory

**Cyclic Switching** `CycleActiveSlotForward/Backward()`:
- Uses `do-while` loop to wrap index
- Skips empty slots
- Calls `SetActiveSlotIndex`

**Complete Equip Chain:**

```
Inventory AddItemDefinition
  → QuickBar AddItemToSlot
    → QuickBar SetActiveSlotIndex
      → QuickBar EquipItemInSlot
        → EquipmentManager EquipItem
          → FLyraEquipmentList::AddEntry
            → Spawn EquipmentInstance
            → AbilitySet->GiveToAbilitySystem(ASC, GrantedHandles, Instance as SourceObject)
            → Spawn Equipment Actors
```

## Pickup Definition

### ULyraPickupDefinition

DataAsset defining pickup properties:
- `InventoryItemDefinition` — Item definition added on pickup
- `DisplayMesh` — Display mesh
- `SpawnCoolDownSeconds` — Respawn cooldown
- Pickup/respawn sounds and effects

### ULyraWeaponPickupDefinition

Inherits from ULyraPickupDefinition, adds weapon mesh offset:
- `WeaponMeshOffset` — Weapon mesh position offset
- `WeaponMeshScale` — Weapon mesh scale
