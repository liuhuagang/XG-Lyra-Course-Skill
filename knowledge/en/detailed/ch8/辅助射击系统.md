# Aim Assist System

## Overview

The Aim Assist system is a targeting assistance mechanism on console/controller platforms. It provides **Drag/Tension** and **Slowdown** effects when the reticle is near a target, helping players aim more precisely.

Lecture (099) content primarily consists of Blueprint screenshots. This document records structural information confirmable from the existing course material.

## Core Concepts

### Drag/Tension

- When the reticle moves past a target, camera/aim movement speed is affected by a "drag" force
- Manifests as a "sticky" feeling when the reticle moves near a target, making it harder to slide past
- Reduces the difficulty of fine-tuning aim

### Slowdown

- When the reticle hovers over or points toward a target, aim movement speed decreases
- Enables finer aiming adjustments on the target
- Used in conjunction with Drag

## Implementation Reference

- Aim Assist logic is implemented in Blueprint
- Involves adjustments to target detection and input processing
- Only affects controller input; keyboard and mouse are typically unaffected
