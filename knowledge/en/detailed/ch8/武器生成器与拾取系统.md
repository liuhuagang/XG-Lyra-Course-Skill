# Weapon Spawner & Pickup System

## Overview

The Weapon Spawner is an Actor that generates pickupable weapons in the scene. Players collect weapons into their inventory on collision.

UCLASS(Blueprintable, BlueprintType)
class ALyraWeaponSpawner : public AActor
{
    ULyraWeaponPickupDefinition* WeaponDefinition;  // Weapon pickup definition

    bool bIsWeaponAvailable;          // Replicated, whether the weapon is available
    float CoolDownTime;               // Cooldown time after pickup
    float CheckExistingOverlapDelay;  // Delay before checking for overlaps after weapon becomes available

## Core Flow

### Pickup Flow (OnOverlapBegin)

1. Player enters collision volume, triggers `OnOverlapBegin`
2. Checks `bIsWeaponAvailable` — only pickup when available
3. Calls `AttemptPickUpWeapon(Pawn)`
4. AttemptPickUpWeapon calls `GiveWeapon(WeaponItemClass, Pawn)` (BlueprintNativeEvent)
5. `GiveWeapon` Blueprint implementation: Creates InventoryItemInstance and adds to player inventory
6. On successful pickup, calls `StartCoolDown()` to begin cooldown

### Cooldown Flow (StartCoolDown)

1. Calls `SetWeaponPickupVisibility(false)` — hides weapon
2. Sets `bIsWeaponAvailable = false`
3. Starts cooldown timer (calls OnCoolDownTimerComplete after CoolDownTime)
4. Drives cooldown progress indicator via `CoolDownPercentage`

### Respawn Flow

1. Cooldown timer triggers `OnCoolDownTimerComplete`
2. Sets `bIsWeaponAvailable = true`
3. Calls `SetWeaponPickupVisibility(true)` — shows weapon
4. Calls `PlayRespawnEffects()` — respawn effects
5. After `CheckExistingOverlapDelay`, calls `CheckForExistingOverlaps()`
6. CheckForExistingOverlaps detects if a Pawn is already waiting on the pad

### Network Replication

- `bIsWeaponAvailable` uses `ReplicatedUsing = OnRep_WeaponAvailability`
- OnRep_WeaponAvailability handles client-side visibility state and effect sync
- Cooldown percentage is computed locally on the client via Tick

## Pickup Definition

### ULyraPickupDefinition

DataAsset defining pickup properties:
- `InventoryItemDefinition` — Item definition added on pickup
- `DisplayMesh` — Pickup display mesh
- `SpawnCoolDownSeconds` — Respawn cooldown time
- Pickup and respawn sounds/effects

### ULyraWeaponPickupDefinition

Inherits from ULyraPickupDefinition, adds weapon mesh parameters:
- `WeaponMeshOffset` — Weapon mesh position offset
- `WeaponMeshScale` — Weapon mesh scale
