# Automated Testing System

## Overview

Lyra's automated testing system consists of two frameworks: CQTest-based functional tests (in the ShooterTests plugin) and Gauntlet-based boot tests. CQTest provides a structured functional testing framework supporting map tests, animation tests, network tests, input simulation, and device property tests. Gauntlet provides automated deployment and boot detection.

## CQTest Functional Test Framework

CQTest is UE5's modern testing framework, integrated by Lyra in the `ShooterTests` plugin.

### Test Basic Pattern

```cpp
TEST_CLASS_WITH_FLAGS(TestClassName, "ProjectName.TestCategory", EAutomationTestFlags::ApplicationContextMask | EAutomationTestFlags::ProductFilter)
BEFORE_EACH
{
    // Use FMapTestSpawner to spawn characters in the test map
    MapTestSpawner = MakeUnique<FMapTestSpawner>(TEXT("/Game/Maps/TestMap"));
    MapTestSpawner->BeginSpawning();
}
AFTER_EACH { }

TEST_METHOD(TestMethodName)
{
    // Execute damage test: set damage value via SetByCaller Magnitude
    DoDamageToPlayer(TargetPlayer, DamageAmount);
    ASSERT_THAT(Health, NumericEqual(ExpectedHealth));
}
```

## Gauntlet Automation Framework

Gauntlet is UE5's automated testing framework. Lyra implements boot detection via `ULyraTestControllerBootTest`.

### Execution Flow

```
RunUAT
    → RunUnreal with -test=LyraTestControllerBootTest
    → Game starts, Gauntlet controller waits for TestDelay (20 seconds)
    → IsBootProcessComplete() returns true → test passes
```

### ULyraTestControllerBootTest

[LyraTestControllerBootTest.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Tests/LyraTestControllerBootTest.h) / [LyraTestControllerBootTest.cpp](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Tests/LyraTestControllerBootTest.cpp)

Inherits from `UGauntletTestControllerBootTest`, overrides `IsBootProcessComplete()`. Current implementation is a placeholder, using a 20-second hardcoded delay to determine boot completion. Actual useful test logic is not yet implemented (marked with TODO comments; the ideal implementation should check if `ULyraGameInstance` has entered the welcome screen or main menu).

```cpp
UCLASS()
class ULyraTestControllerBootTest : public UGauntletTestControllerBootTest
{
    const double TestDelay = 20.0f;

    virtual bool IsBootProcessComplete() const override
    {
        double TimeSinceStart = FPlatformTime::Seconds() - StartTime;
        return TimeSinceStart >= TestDelay;
    }
};
```
