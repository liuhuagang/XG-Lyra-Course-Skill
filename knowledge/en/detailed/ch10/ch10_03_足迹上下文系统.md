# Context Effects System

## Overview

The ContextEffects system is a feedback system in Lyra that dynamically plays footstep sounds and particle effects based on physical surface type and GameplayTag context. The system covers the complete chain from animation notify trigger → interface abstraction → component management → library matching → subsystem effect spawning.

## System Architecture

```
UAnimNotify_LyraContextEffects (Animation Notify)
    → ILyraContextEffectsInterface::AnimMotionEffect (Interface)
    → ULyraContextEffectComponent::AnimMotionEffect_Implementation (Component Implementation)
    → ULyraContextEffectsSubsystem::SpawnContextEffects (Subsystem)
    → ULyraContextEffectsLibrary::GetEffects (Library Matching)
    → UGameplayStatics::SpawnSoundAttached / UNiagaraFunctionLibrary::SpawnSystemAttached
```

## Library: ULyraContextEffectsLibrary

[LyraContextEffectsLibrary.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Feedback/ContextEffects/LyraContextEffectsLibrary.h) / [LyraContextEffectsLibrary.cpp](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Feedback/ContextEffects/LyraContextEffectsLibrary.cpp)

Data asset storing the `EffectTag + Context(TagContainer) → Sound/NiagaraSystem` mapping relationship.

### Key Structure

```cpp
USTRUCT(BlueprintType)
struct FLyraContextEffects
{
    FGameplayTag EffectTag;                      // Effect tag (e.g., Footstep.Run)
    FGameplayTagContainer Context;               // Context tags (e.g., SurfaceType.Concrete)
    TArray<FSoftObjectPath> Effects;             // Soft references to SoundBase / NiagaraSystem
};
```

### Matching Logic

Uses `MatchesTagExact` + `HasAllExact` for exact matching, not hierarchical matching:

```cpp
if (Effect.MatchesTagExact(ActiveContextEffect->EffectTag)
    && Context.HasAllExact(ActiveContextEffect->Context)
    && (ActiveContextEffect->Context.IsEmpty() == Context.IsEmpty()))
{
    Sounds.Append(ActiveContextEffect->Sounds);
    NiagaraSystems.Append(ActiveContextEffect->NiagaraSystems);
}
```

## Component Layer: ULyraContextEffectComponent

[LyraContextEffectComponent.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Feedback/ContextEffects/LyraContextEffectComponent.h) / [LyraContextEffectComponent.cpp](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Feedback/ContextEffects/LyraContextEffectComponent.cpp)

ActorComponent implementing `ILyraContextEffectsInterface`, responsible for:

1. **Context Aggregation**: Triple aggregation of incoming Contexts + component's own `CurrentContexts` + physical surface type
2. **Physical Surface Mapping**: Via `bConvertPhysicalSurfaceToBool` flag, maps the surface type from `HitResult.PhysMaterial` to a GameplayTag using `ULyraContextEffectsSettings`
3. **Lifecycle Management**: Loads `DefaultContextEffectsLibraries` into Subsystem on `BeginPlay`, unloads on `EndPlay`

## Animation Notify: UAnimNotify_LyraContextEffects

[AnimNotify_LyraContextEffects.h](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Feedback/ContextEffects/AnimNotify_LyraContextEffects.h) / [AnimNotify_LyraContextEffects.cpp](file:///d:/UPS/GitLab/XGUnrealNote/Courses/Lyra-Deep-Dive/code/Lyra/Source/LyraGame/Feedback/ContextEffects/AnimNotify_LyraContextEffects.cpp)

Animation notify triggered when animation playback reaches a specific frame. Supports optional LineTrace detection to obtain HitResult and physical material.

### Execution Flow

1. **Optional Trace**: Controls whether to perform LineTrace via `bPerformTrace`
2. **Find Interface Implementor**: Iterates Owner and its Components, finds objects implementing `ILyraContextEffectsInterface`
3. **Dispatch Call**: Calls `AnimMotionEffect` on each implementing object
4. **Editor Preview**: In editor, gets and spawns effects directly from Library

### Helper Structs

- `FLyraContextEffectAnimNotifyVFXSettings`: Niagara scale
- `FLyraContextEffectAnimNotifyAudioSettings`: Volume/pitch multipliers
- `FLyraContextEffectAnimNotifyTraceSettings`: TraceChannel, offsets, ignored Actors
- `FLyraContextEffectAnimNotifyPreviewSettings`: Editor preview configuration

## Key Design Points

1. **Interface Decoupling**: Animation notify does not directly depend on component type; discovers implementing objects via interface
2. **Exact Matching**: Library uses `MatchesTagExact` + `HasAllExact` for precise matching, not hierarchical inheritance
3. **Context Aggregation**: Triple aggregation of incoming Contexts + default Contexts + physical surface type
4. **Lifecycle Binding**: Component `BeginPlay`/`EndPlay` automatically registers/unregisters Libraries
5. **Configurable Mapping**: Physical surface mapping is configured via `UDeveloperSettings` in `DefaultGame.ini`
